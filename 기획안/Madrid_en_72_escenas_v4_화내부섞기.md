# 《Madrid en 72 escenas》 v4 — 화 안에서 섞기 (이슈 비중 · 언어 난이도 혼합)

> v3은 **화 단위**로 이슈와 난이도를 섞었다(화마다 ●/◐/○, A2/B1/B2/C1 한 가지). v4는 **한 화 안에서** 두 가지를 섞는다.
> 화 하나가 하나의 난이도, 하나의 이슈 무게로 평평하게 가지 않고, 100턴 안에서 오르내린다.
> 대사는 스페인어로 처음부터 창작한다. 네덜란드판 문장은 가져오지 않는다. 화 제목·상황·인물은 v2/v3과 같다.
> 상태: 초안. 구간별 값은 시드 2026 무작위 배정이며, 대본 작성 때 장면에 맞게 조정한다.

## 1. 무엇이 달라졌나

| 항목 | v3 | **v4** |
|---|---|---|
| 난이도 | 화마다 1개 (A2 / B1 / B2 / C1) | **주 난이도 1개 + 100턴을 5구간(20턴씩)으로 나눠 구간마다 다른 난이도** |
| 이슈 | 화마다 ● / ◐ / ○ | **화마다 이슈 곡선**: 5구간에 0~3의 강도를 배정 (잔잔, 정점, 후반 폭발 등 6가지 모양) |
| 한 화의 느낌 | 균일 | 가벼운 수다 → 이슈가 뜸 → 다시 일상 같은 **파동** |
| ●/◐/○ | 화의 성격 | **이슈 상한선**: ●는 강도 3까지, ◐는 2까지, ○는 1까지만 올라간다 |

## 2. 언어 난이도 섞기 규칙

주 난이도(화 제목 옆 표시)는 유지하되, 20턴 구간마다 다른 난이도를 허용한다.

1. **구간 난이도는 주 난이도 ±1 단계**까지. (A2 화는 A2·B1, B1 화는 A2·B1·B2, C1 화는 B2·C1)
2. 한 화에 **난이도가 최소 2종류** 들어간다. 모든 구간이 같은 단계인 화는 없다.
3. 난이도를 올리는 장치는 **문법을 억지로 올리는 것이 아니라 화자와 상황을 바꾸는 것**이다.

| 난이도 요소 | 쓰는 방법 |
|---|---|
| 구간이 올라간다(+1) | 말 빠른 인물 등장, 노인·관리직 화자의 관용구, 전화·방송 같은 불완전한 음질, 공식 문서 낭독 |
| 구간이 내려간다(−1) | 학습자 역할(이민자·어린이)에게 설명해 주는 장면, 되묻기, 재확인 |
| 구간 경계 | 난이도가 바뀌는 지점에 **되묻기·풀어쓰기**를 넣어 학습자가 따라오게 한다 (예: "¿Cómo? / O sea, que…") |

4. 한글 해석의 난이도 표시는 구간별로 달라도 된다. 학습 포인트 정리는 **구간 난이도별로 묶어** 쓴다.

## 3. 이슈 비중 섞기 규칙

이슈 강도는 5구간에 0~3으로 매긴다.

| 강도 | 뜻 | 대사 예시(스페인어로 쓸 때의 기준) |
|---|---|---|
| 0 | 이슈 없음, 순수 생활·감정 | 인사, 음식, 농담 |
| 1 | 배경 | 한마디 스침 ("Está todo carísimo, ¿no?") |
| 2 | 의견 교환 | 두 입장이 가볍게 부딪침 |
| 3 | 이슈가 장면의 중심 | 갈등, 설명, 결정 |

곡선 모양 6가지(구간 순서 1~5):

| 모양 | 의미 | 예 |
|---|---|---|
| 잔잔형 | 이슈는 배경. 최대 1~2 | 0-1-1-1-0 |
| 정점형 | 중반에 올라갔다가 풀림 | 0-1-3-2-1 |
| 후반폭발형 | 가볍게 시작해 끝에서 이슈가 터짐 | 0-0-1-2-3 |
| 초반충격형 | 이슈로 시작해 일상으로 가라앉음 | 3-2-1-1-0 |
| 파도형 | 이슈가 두 번 올라옴 | 1-3-1-3-1 |
| 반전형 | 평온하다가 다른 방향에서 이슈가 터짐 | 2-2-1-0-3 |

규칙:
1. 이슈 강도 3이 **연속 세 구간을 넘지 않게** 한다 (설교 방지).
2. **강도 3 구간에서는 서로 다른 입장 두 개 이상**이 나온다. 결말은 열어 둔다.
3. 강도 0~1 구간에는 이슈 어휘를 쓰지 않고 장면의 재미(농담, 먹기, 이동)로 채운다.
4. 이슈 어휘와 의견 표현은 **강도 2 이상 구간에서만** 학습 포인트로 정리한다.
5. 민감 소재(폭력·차별)는 강도 3이어도 가해 재현보다 당사자의 대응에 초점을 둔다.
6. 정치인·정당 실명 금지, 사실 확인 대상(법·수치)은 v2 7-2절 체크리스트를 따른다.

검수 기준 추가:
