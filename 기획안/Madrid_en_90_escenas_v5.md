# 《Madrid en 90 escenas》 v5 — 90화 · 120턴 (6부 × 15화)

> v4(72화, 100턴)를 **6부 × 15화 = 90화, 화당 120턴**으로 확장한 최신 기획이다.
> 한 화 안에서 언어 난이도와 이슈 비중을 섞는 v4의 방식을 그대로 쓰되, 100턴 5구간을 **120턴 6구간(20턴씩)**으로 바꿨다.
> 대사는 스페인어로 처음부터 창작한다. 네덜란드판 문장은 가져오지 않는다.
> 상태: 초안. v2·v3·v4 문서는 이 문서로 대체된다(참고용으로 남김).

---

## 1. 한눈에 보기

| 항목 | v4 | **v5** |
|---|---|---|
| 부 구성 | 6부 × 12화 | **6부 × 15화** |
| 총 화수 | 72 | **90** |
| 화당 턴 수 | 100 | **120** (화자 발화 1회 = 1턴, 지문 제외) |
| 총 턴 수 | 7,200 | **10,800** |
| 난이도·이슈 구간 | 20턴 × 5구간 | **20턴 × 6구간** |
| 부 구성 기준 | 생활 영역별 6부 | 같음 (집과 동네 / 이동 / 먹고 마시기 / 일과 행정 / 여가와 축제 / 사람과 관계) |
| 부 안의 화 순서 | v3에서 배열 | **부 안에서도 난이도·이슈를 섞은 순서** (사다리 없음) |

화 형식(대화 120턴 → 낭독 포인트 → 학습 포인트 정리 → 속어 노트 → 한글 해석)은 유지한다.

## 2. 120턴으로 바뀌는 것

1. **구간 6개 × 20턴**: 1~20, 21~40, 41~60, 61~80, 81~100, 101~120턴.
2. 화당 길이가 20% 늘어나므로 **화 안의 장면을 한 번 더 전환**할 여유가 생긴다. 구간 6개 중 한두 구간은 인물이 들어오거나 장소·매체(전화, 방송)가 바뀌는 전환 구간으로 쓴다.
3. 이슈 곡선도 6값으로 늘어, 이슈가 한 번 올라가고 풀리고 다시 올라오는 모양(파도형)을 더 자연스럽게 쓸 수 있다.
4. 부 단위 분량: 15화 × 120턴 = 1,800턴. 6부 합계 10,800턴.
5. 검수 기준 1번이 "대화 120턴 = 한글 해석 120턴"으로 바뀐다.

## 4. 언어 난이도 섞기 규칙 (120턴 6구간)

1. 구간 난이도는 **주 난이도 ±1 단계**까지.
2. 한 화에 난이도가 **최소 2종류** 들어간다.
3. 올리는 장치는 문법을 억지로 올리는 것이 아니라 **화자·상황**: 말 빠른 인물, 노인·관리직 화자의 관용구, 전화·방송, 공문 낭독.
4. 내리는 장치: 학습자 역할(이민자·어린이)에게 설명해 주는 장면, 되묻기, 재확인.
5. 난이도가 바뀌는 지점에는 되묻기·풀어쓰기("¿Cómo? / O sea, que…")를 넣는다.
6. 학습 포인트 정리는 **구간 난이도별로 묶어** 쓴다.

## 5. 이슈 비중 섞기 규칙 (120턴 6구간)

| 강도 | 뜻 | 기준 |
|---|---|---|
| 0 | 이슈 없음 | 인사, 음식, 농담 |
| 1 | 배경 | 한마디 스침 |
| 2 | 의견 교환 | 두 입장이 가볍게 부딪침 |
| 3 | 이슈가 장면의 중심 | 갈등, 설명, 결정 |

곡선 모양 6가지: **잔잔형**(최대 1~2) / **정점형**(중반에 올라갔다 풀림) / **후반폭발형**(끝에서 터짐) / **초반충격형**(이슈로 시작해 가라앉음) / **파도형**(두 번 올라옴) / **반전형**(평온하다가 다른 방향에서 터짐).

규칙:
1. 강도 3은 **연속 세 구간을 넘지 않는다**(설교 방지).
2. 강도 3 구간에서는 **서로 다른 입장 두 개 이상**이 나오고, 결말은 열어 둔다.
3. 강도 0~1 구간은 이슈 어휘 없이 장면의 재미로 채운다.
4. 이슈 어휘와 의견 표현은 강도 2 이상 구간에서만 학습 포인트로 정리한다.
5. 민감 소재(폭력·차별)는 가해 재현보다 당사자의 대응에 초점을 둔다.
6. 정치인·정당 실명 금지. 사실 확인(법·수치)은 v2 7-2절 체크리스트를 따른다.

## 6. 화별 템플릿

```
# N부 M화. Título en español (한글 제목)
난이도: 주 B1 | 구간: A2→B1→B2→B1→B1→B2 | 형식: 전화 | 장소: ...
이슈: 주 ● 주거 위기 | 곡선: 0-1-3-2-1-0 (정점형) | 입장: A 세입자 / B 집주인
상황 카드: 목표 + 걸림돌 + 반전/해소
학습 포인트: ...

## 대화            ← 120턴
## 낭독 포인트
## 학습 포인트 정리   ← 구간 난이도별로 묶음
## 속어 노트
## 한글 해석         ← 스페인어 → 한국어, 같은 120턴
```

검수 기준:
1. 대화 120턴 = 한글 해석 120턴
2. 헤더의 인물과 실제 발화자 일치
3. 모든 섹션 존재, 미완성 표시 없음
4. 번역투 없음(소리 내어 읽기)
5. 구간별 난이도가 ±1 단계 안이고, 2종류 이상인가
6. 강도 3 구간에서 입장이 둘 이상이고 결말이 열려 있는가
7. 강도 3이 연속 세 구간 이내인가
