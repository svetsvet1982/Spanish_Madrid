# 《Paris en 90 scènes》 v1 — 90화 · 120턴 (6부 × 15화)

> 스페인판 `Madrid en 90 escenas` v5의 구조(6부 × 15화, 화당 120턴, 20턴 × 6구간)를 그대로 쓰는 **프랑스어판** 기획이다.
> 대사는 프랑스어로 처음부터 창작한다. 스페인어판 문장을 번역하지 않는다. 장면·소재도 프랑스(파리와 일드프랑스)에서 일어나는 일로 새로 정했다.
> 상태: 초안.

---

## 1. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 부 구성 | 6부 × 15화 = 90화 |
| 화당 턴 수 | 120 (화자 발화 1회 = 1턴, 지문 제외), 총 10,800턴 |
| 구간 | 20턴 × 6구간, 구간마다 CEFR 난이도(A2~C1)와 이슈 강도(0~3)를 따로 둔다 |
| 이슈 등급 | ● 30 / ◐ 30 / ○ 30화 (상한 강도: ● 3, ◐ 2, ○ 1) |
| 지역 | 파리와 근교(일드프랑스) 구어. 필요하면 지방 억양은 인물 설정으로만 쓴다 |
| 화 형식 | 대화 120턴 → 낭독 포인트 → 학습 포인트 정리 → 속어 노트 → 한글 해석 |

난이도·이슈 곡선·모양·등급은 스페인판 배정표(v5 7절)의 값을 그대로 이어받았다. 같은 번호의 화는 두 판에서 **같은 길이·같은 강도 곡선**을 갖지만 **내용은 다르다**.

## 2. 프랑스어판에서 달라지는 점

1. **tu / vous**: 스페인어보다 구분이 엄격하다. 화마다 인물 관계에 따라 정하고, 호칭이 바뀌는 순간("On peut se tutoyer ?")을 장면으로 쓸 수 있다.
2. **발음 노트**(낭독 포인트): 비음 모음(on, an, in), 연음·연성(liaison), 프랑스어 r, u / ou 구분, 묵음 e와 어말 자음. 철자와 발음의 불일치를 짚는다.
3. **속어 노트**: 일상 구어(*bouffer, boulot, ouf, grave, du coup, genre*), 베를랑(verlan: *meuf, relou, ouf*), 구어 부정 생략(*j'sais pas, y'a pas*), *ne* 생략을 짚는다. 욕설은 쓰지 않는다.
4. **사회 소재는 프랑스의 일상 제도**에서 가져온다: 월세 인상 상한, 동계 퇴거 유예(trêve hivernale), 공동주택 총회(copropriété), 가족수당·건강보험 서류, 도청 예약, 저공해구역(ZFE), 파업과 대중교통, 식권(ticket-resto), 요양시설(EHPAD). 정당·정치인 실명은 쓰지 않는다.
5. **식사·카페 규칙**: 서비스 포함 가격과 팁, *formule du midi*, *apéro*, 빵집(boulangerie) 등 프랑스 고유 장면을 쓴다.
6. 법·금액·제도는 모두 가공으로 처리하고, 속어 노트에 명시한다.

## 3. 난이도·이슈 규칙 (스페인판과 동일)

- 구간 난이도는 주 난이도 ±1 단계, 한 화에 2종류 이상. 올리는 장치는 화자와 상황(말 빠른 화자, 공문, 방송), 내리는 장치는 되묻기와 풀어쓰기("Pardon ? / Autrement dit…").
- 이슈 강도 0 없음 / 1 배경 / 2 의견 교환 / 3 이슈가 중심. 강도 3은 연속 세 구간 이내, 입장 둘 이상, 열린 결말.
- 가해 재현보다 당사자의 대응을 쓴다. 설교하지 않는다.
- 검수: 대화 120턴 = 한글 해석 120턴 / 인물과 발화자 일치 / 섹션 완비 / 번역투 없음 / 난이도 ±1·2종류 이상 / 강도 3 구간의 입장·결말 / 강도 3 연속 3구간 이내.
