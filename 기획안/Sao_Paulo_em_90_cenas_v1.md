# 《São Paulo em 90 cenas》 v1 — 90화 · 120턴 (6부 × 15화)

> 스페인판 `Madrid en 90 escenas` v5, 프랑스판 `Paris en 90 scènes` v1과 같은 구조(6부 × 15화, 화당 120턴, 20턴 × 6구간)의 **브라질 포르투갈어판** 기획이다.
> 대사는 브라질 포르투갈어(상파울루 구어)로 처음부터 창작한다. 다른 판 문장을 번역하지 않는다. 장면·소재도 브라질(상파울루와 근교) 일상에서 새로 정했다.
> 상태: 초안.

---

## 1. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 부 구성 | 6부 × 15화 = 90화 |
| 화당 턴 수 | 120 (화자 발화 1회 = 1턴, 지문 제외), 총 10,800턴 |
| 구간 | 20턴 × 6구간, 구간마다 CEFR 난이도(A2~C1)와 이슈 강도(0~3)를 따로 둔다 |
| 이슈 등급 | ● 30 / ◐ 30 / ○ 30화 (상한 강도: ● 3, ◐ 2, ○ 1) |
| 지역·언어 | 브라질 포르투갈어, 상파울루 도시 구어. 리우·북동부·남부 말씨는 인물 설정으로만 쓴다. 유럽 포르투갈어 표현은 쓰지 않는다 |
| 화 형식 | 대화 120턴 → 낭독 포인트 → 학습 포인트 정리 → 속어 노트 → 한글 해석 |

난이도·이슈 곡선·모양·등급은 다른 판 배정표 값을 그대로 이어받았다. 같은 번호의 화는 길이와 강도 곡선이 같고 내용은 다르다.

## 2. 브라질판에서 달라지는 점

1. **2인칭**: 상파울루 구어는 *você*가 기본이고 *a gente*(우리)를 많이 쓴다. *tu*는 지역 인물(리우·남부·북동부)의 말씨로만 쓴다. *o senhor / a senhora*는 연장자·공식 상황에 쓴다.
2. **발음 노트**(낭독 포인트): 비음 모음(*ão, õe, ã, em/en*), t·d 뒤 i의 구개음화(*tchi, dji*), 어말 o→[u]·e→[i], 어두·어중 r의 [h]음, *lh, nh*, 약화 모음과 연결 발음.
3. **속어 노트**: *cara, mano, né, tá, bora, beleza, legal, valeu, pô, a gente*, 구어 축약(*tô, tá, pra, cê*), 지역 어휘 차이(*mandioca/aipim/macaxeira* 등). 욕설은 쓰지 않는다.
4. **사회 소재는 브라질 일상 제도**에서 가져온다: 월세 조정과 *condomínio*·IPTU, 침수와 방재, 교통카드(Bilhete Único)와 요일제(rodízio), 배달·호출 앱 노동, *CLT* 대 *PJ*, 공공의료(SUS)와 민간 보험, 공증소 서류, Pix, 반값 입장권(meia-entrada), 6월 축제, 요양시설. 정당·정치인 실명은 쓰지 않는다.
5. **식사 규칙**: *prato feito*, 서비스 10%, *cafezinho*, *padaria*, *churrasco*, *feira*.
6. 법·금액·제도는 모두 가공으로 처리하고, 속어 노트에 명시한다.
7. **민감 소재**(정치 양극화, 종교, 인종, 치안·폭력, 계층 격차)는 생활 장면의 한 구석으로만 다루고, 당사자의 대응을 쓴다. 강도 3에서도 어느 쪽도 정답으로 만들지 않는다.

## 3. 난이도·이슈 규칙 (다른 판과 동일)

- 구간 난이도는 주 난이도 ±1 단계, 한 화에 2종류 이상. 올리는 장치는 화자와 상황, 내리는 장치는 되묻기와 풀어쓰기("Como assim? / Quer dizer…").
- 이슈 강도 0 없음 / 1 배경 / 2 의견 교환 / 3 이슈가 중심. 강도 3은 연속 세 구간 이내, 입장 둘 이상, 열린 결말. 설교하지 않는다.
- 검수: 대화 120턴 = 한글 해석 120턴 / 인물과 발화자 일치 / 섹션 완비 / 번역투 없음 / 난이도 ±1·2종류 이상 / 강도 3 구간의 입장·결말 / 강도 3 연속 3구간 이내.
