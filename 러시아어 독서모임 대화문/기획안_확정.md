# 《Читальня на Чистых》 (체스트이예의 독서실) — 확정 기획안

러시아어 학습용 장편 대화문. 모스크바 러시아 고전문학 독서 모임에서 남녀 한 쌍이 만나 연인이 되는 과정을 그린다.

## 1. 확정 사양

| 항목 | 내용 |
|---|---|
| 구성 | **4부 × 16화 = 64화**, 1화 = **100턴** (총 6,400턴) |
| 1화 구조 | 5씬 × 20턴 (도입 → 전개 → 인용 장면 → 고조 → 여운) |
| 난이도 | 화마다 B1~C2를 혼합 (부 안에서 파도형, 전체 상승) |
| 인용 | 화당 1~2회. **러시아 문학 작품 또는 속담**에서만 인용 |
| 화 끝 부록 | 인용 원문, 한글 해석, 쓰인 맥락, 출전 |
| 표기 | 대화문은 러시아어만. 해설은 한글 |
| 턴 | 화자 1명의 1회 발화 |

### 레벨별 언어 특징
- **B1:** 일상 회화, 메신저, 실용 장면. 짧은 문장과 기본 접속사.
- **B2:** 간접화법, 가정법, 분사, 감정 표현, 토론 어휘.
- **C1:** 부동사구, 동사 명사형, 관용구, 격식·비격식 전환, 반어.
- **C2:** 고어, 문체적 도치, 말장난, 속담, 문학적 인용을 대화에 녹이기.

## 4. 인용 규칙

1. 출전은 러시아 문학 작품(소설, 희곡, 시)과 러시아 속담으로 한정한다.
2. 인용문은 대화 안에서 인물이 직접 읊거나 언급한다. 인용 위치(턴 번호)를 화 끝 부록에 적는다.
3. 부록은 **원문 → 한글 해석 → 쓰인 맥락(작품 속 맥락과 대화 속 맥락) → 출전** 순서로 쓴다.
4. 판본마다 행갈이가 다를 수 있는 시는 부록에 "판본에 따라 행갈이가 다를 수 있음"을 병기한다.
5. 일부 인용은 레벨에 맞춰 대화 속에서 부분만 사용하고, 부록에서 전체 맥락을 설명한다.

- 6화(10월): «вы» → «ты» 전환. 7화부터 밤 메신저 대화.
- 11화: 베라의 〈타티야나 편지〉 인용 사건 → "솔직하게, 그러나 천천히", "모르면 바로 묻는다"가 두 사람의 규칙.
- 12화: 올가 등장, 안드레이가 베라를 '친구'로 소개하지 않음. "그 말(слово)"을 찾기로 함.
- 13화: 야스나야 폴랴나, 톨스토이의 무덤 앞 침묵("서두르지 않아도 된다").
- 14화: 안드레이가 부모의 이혼을 고백. 작은 약속(매주 목요일 먼저 오기)을 맺고 처음 손을 잡음.
- 15화: 첫눈, 푸시킨 〈겨울 아침〉. 새해 모임에서 서로에게 '비밀 선물'을 가져오기로 함.
- 16화: 둘 다 이미 제안을 받았음(베라: 에르미타주 3개월 연수를 거절, 안드레이: 올가의 시니어 에디터 자리를 보류). 1월 10일 MKhT 〈갈매기〉 표 두 장.

**반복 소재 (수미상관용)**
- 남의 의자 / 5분 늦게·일찍 도착하기 내기
- 보온병, 우산, 사과 파이와 사과 모양 책갈피
- «Как бы чего не вышло» (안드레이의 '상자 속의 사나이' 별명)
- 《백야》 첫 문장(7화) ↔ 마지막 문장(4부 16화)
- 알리사의 수첩 «А + В»

**시간선**
- 1부: 9월 첫째 목요일 ~ 12월 셋째 목요일
- 2부 첫 화: 12월 25일 송년 모임 → 1월 10일 〈갈매기〉

## 7. 2부에서 확정된 설정 (3부 이후 작성 시 반드시 유지)

**시간선 보정:** 2부의 마지막(첫 고백·첫 키스)은 **3월 1일**이다. 기획안 3부 표의 〈Тайна〉는 3월 초부터 시작한다.

**관계의 도착점 (2부 16화)**
- 볼쇼이 카멘니 다리에서 안드레이가 «спасибо / прости / люблю»를 말하고 베라도 «люблю»라고 답한다. 첫 키스. 두 사람은 '파라(пара, 한 쌍)'가 된다.
- 3부 〈Тайна〉의 이유: 12화(단체 채팅 사고)와 리디야의 '험담 수업' 때문에, 스스로 익숙해질 때까지 모임에는 천천히 알리기로 한다.

**각자의 결정**
- 베라: 에르미타주 3개월 연수를 거절했으나 "미래 프로젝트 후보 명단에는 남겨 달라"고 요청했다. (3부 〈Предложение из Петербурга〉에서 더 큰 제안, 1년 계약이 온다.)
- 안드레이: 올가(«Горизонт»)의 제안을 거절. 사장 이고리 리보비치의 제안(시니어 에디터 + '잊힌 러시아 고전 시리즈'를 직접 기획)을 수락. 3월 2일 월요일에 사장에게 통보.

**새로 정해진 인물·배경**
- 안드레이의 집: 포크롭카 10번지 12호, 책이 바닥에 쌓여 있다. 어머니 엘레나 세르게예브나는 스트로기노에 산다. 1952년판 푸시킨 선집(베라가 수선)을 어머니께 선물했다.
- 베라의 집: 크라스니예 보로타, 초록색 부엌, 할머니가 물려준 식탁(칼자국). 어머니는 파이를 굽는 분이고, 약혼자였던 데니스(카잔 출신 치과의사)와는 '사람이냐 일이냐'로 헤어졌다.
- 드미트리 보로닌: 베라의 동료 복원사(8년), 같은 부서 마리나와 결혼 예정. 안드레이를 처음 질투하게 만든 인물.
- 마르크: 3년 전 아내가 떠남("불편하다는 말을 제때 못 했다"). 속 깊은 조언자 역할이 열림.
- 리디야: 남편 그리고리(물리학자)와 34년 결혼, 15년 전 사별. 크르이조브니크 잼 6년산.
- 파벨: 15년 전 조기 은퇴 후 아내와 카렐리야 텐트 여행. 투폴레프의 묘를 매달 찾는다.
- 알리사: 연인 일리야와 이별(크리스티나). 논문 쓰기를 되찾음. 클럽 여섯 명을 '지붕 위의 여섯 별'이라 부름.
- 야간 경비 니콜라이 페트로비치: 전직 역사 교사. "말은 은, 침묵은 금—하지만 겁에서 나온 침묵도 있다."

**반복 소재 / 규칙**
- 블록노트 «Вера говорит» (안드레이가 베라의 말을 적음), 사과 모양 책갈피, 보온병.
- "작은 약속": 목요일에 먼저 도착하기(안드레이) ↔ 5분 늦게 도착하기(베라). 2부 10화 이후 한 번 깨졌으나 15화에서 안드레이가 처음 2분 17초 지각, 베라가 허락함.
- "모르면 바로 묻는다 / 솔직하게, 그러나 천천히 / 침묵은 중립이 아니다."
- 목요일 밤 통화(7화), 머리글자 놀이(13화): «Прости, я не умею говорить вовремя, но учусь.» / «Я прочла. Дай мне три дня.»
- 《백야》 첫 문장(7화) ↔ 마지막 문장(4부 16화).

## 8. 3부에서 확정된 설정 (4부 작성 시 반드시 유지)

**시간선:** 3/5 클럽 → 3/21 얼음 풀림 → 4/4 베라 부모님 → 4월 중순 슈빈 → 4/30 뇌우(모임에 관계 공개) → 5/2~3 다차 → 5/14 에르미타주 1년 계약 제안(7/1 시작, 6/15까지 답변) → 5/23 멜리호보 → 5/29 삽산·백야 → 6/1 다툼 → 6/3~4 리디야의 충고 → 6/11 시즌 마지막 모임 → 6/14 수락 결정 → 6/16 계약서 서명 → 6/20 두 어머니의 만남 → 6/21 네스쿠치니 산책 → 6/27 빈 집 → **6/28 레닌그라드 역 출발**.

**결정·상태**
- 베라: 에르미타주 복원부 1년 계약(7/1~다음 해 6/30). 상트페테르부르크 바실리옙스키 섬의 직원 숙소(마당 쪽 창문), 휴가 28일. 모스크바 집은 그대로 두고 안드레이가 열쇠를 가지고 꽃에 물을 준다.
- 안드레이: 시니어 에디터. 〈잊힌 이름들의 도서관〉 시리즈 첫 책은 오도옙스키 《러시아의 밤》. 작가 슈빈과의 작업 관계 정립. 《예브게니 오네긴》(독서실 책)은 안드레이가 보관.
- **사람과 사람의 계약(7조):** 매일 5분 통화(침묵 통화 허용) / 2주마다 한 명이 방문 / 힘들면 반드시 한 줄 알림 / 인용으로 사랑을 농담거리로 만들지 않기 / 등. 모임 친구들은 '공개된 비밀'을 알고 있다.
- 부모님: 베라의 아버지 안드레이 니콜라예비치(화학자, 〈화학과 생활〉, 사과나무 '안토놉카'), 어머니 이리나 파블로브나, 남동생 미샤. 안드레이의 어머니 옐레나 세르게예브나(스트로기노)와 두 어머니는 6/20에 만나 레시피와 전화번호를 교환했다.
- 리디야의 사모바르를 베라가 빌려 간다("9월 또는 언제든 읽기실로 돌아올 때 가져오라").
- 파벨이 만든 책갈피(체스트예 프루디 엽서), 베라의 체호프 책에 꽂힘.

**반복 소재 (4부 계승):** 〈Я хочу〉 vs 〈Я боюсь〉, 〈мы〉 vs 〈ты〉, 작은 약속, 매일 통화, 두 도시/한 선, 블록노트 «Вера говорит», 백야 첫 문장.
- 4부 시작: 7월 첫 주(베라의 첫 출근) → 이듬해 6월(마지막 결정). 4부 16화의 마지막 문장은 《백야》 마지막 문장과 호응한다.
