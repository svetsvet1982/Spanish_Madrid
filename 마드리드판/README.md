## 점검 결과 (1부)

- 15화 모두 대화 120턴 = 한글 해석 120턴, 지문 줄 수 일치, 다섯 섹션 모두 존재 (스크립트로 검증).
- 화자 순서가 대화와 한글 해석에서 일치.
- 화의 독립성: 각 화는 따로 읽혀도 된다. 같은 건물 인물이 가볍게 다시 나오는 곳(2화의 사라·켄지, 5화의 브루노·크로케타, 7화의 알바·토마스)은 보너스 호응이다.
- 법·금액·제도(월세 인상, 보증 기간, 분담금, 점유 절차 등)는 모두 가공이며, 실제 적용은 작성 전에 확인이 필요하다.
