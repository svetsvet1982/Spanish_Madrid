# 3부 4화. Reservamos para ocho (여덟 명 예약)
난이도: 주 B1 | 구간: B1→B1→B2→B1→B1→B1 | 형식: 전화 | 장소: 전화 통화(루시아는 집, 루벤은 식당 카운터) | 시간: 수요일 오전 11시
등장인물: Lucía, Rubén
이슈: 주 ○ 단체 예약과 식당 운영 | 곡선: 0-1-1-0-1-0 (잔잔형, 상한 1) | 입장: 해당 없음(생활 장면. 노쇼 이야기가 한마디 스침)
상황 카드: 루시아는 토요일 점심에 할머니 칠순 잔치를 열려고 식당에 전화한다. 여덟 명 자리, 시간, 메뉴, 어린이 의자, 휠체어가 들어올 문까지 확인해야 한다. 걸림돌은 식당에 여덟 명짜리 탁자가 없다는 것. 결말은 테라스와 실내 탁자를 붙여서 예약이 잡히는 것.
학습 포인트: 전화 예약 표현(Quería reservar…, ¿A nombre de quién?) · 인원·시간·날짜 · 확인과 변경 · 접속법 맛보기(Para que quepamos) · 요일과 시간 표현

## 대화
(Miércoles, once de la mañana. Lucía llama desde casa. Rubén contesta en la barra de la Taberna Los Parrales, con el murmullo de la cocina detrás.)
Rubén : Taberna Los Parrales, dígame.
Lucía : Buenos días. Quería reservar una mesa para el sábado.
Rubén : Claro. ¿Para cuántas personas?
Lucía : Para ocho. Es la comida de cumpleaños de mi abuela.
Rubén : Qué bien. ¿A qué hora querrían venir?
Lucía : A las dos y media, si es posible.
Rubén : Déjeme mirar el libro de reservas.
Lucía : Sí, sin prisa.
Rubén : Para ocho... a esa hora no me queda una mesa grande.
Lucía : ¿No? Qué pena.
Rubén : Tengo dos mesas de cuatro en el comedor.
Lucía : ¿Y se pueden juntar?
Rubén : Se pueden juntar, sí. Pero quedan un poco estrechas.
Lucía : Con mi familia, estrechas es lo normal.
Rubén : Ja, ja. Entonces las juntamos.
Lucía : Genial. ¿Hay que dejar algo de señal?
Rubén : No, para ocho no pedimos señal. Solo un teléfono.
Lucía : Vale. Le doy el mío: seis, uno, cinco, dos, tres, cuatro, cuatro, siete, nueve.
Rubén : Seis, uno, cinco, dos, tres, cuatro, cuatro, siete, nueve. Perfecto.
Lucía : Sí, ese es.
Rubén : ¿A nombre de quién pongo la reserva?
Lucía : A nombre de Lucía Mora Prieto.
Rubén : Mora, con una erre, ¿verdad?
Lucía : Sí, una sola erre. Y Prieto, con pe.
Rubén : Anotado. Mesa para ocho, sábado, dos y media.
Lucía : ¿Puedo preguntar algo sobre alergias?
Rubén : Claro. ¿Alguien es alérgico?
Lucía : Mi tío no puede comer frutos secos.
Rubén : Lo apunto. La cocina avisa a todos los platos.
Lucía : Qué tranquilidad. Gracias.
Lucía : Una cosa más. Mi abuela usa silla de ruedas.
Rubén : Ah, ya. ¿Plegable o grande?
Lucía : Plegable. Es ligera.
Rubén : Entonces no hay problema. La puerta principal es ancha.
Lucía : ¿Hay escalones?
Rubén : Uno, muy pequeño. Y tenemos una rampa de madera.
Lucía : Perfecto. Eso me quita un peso de encima.
Rubén : Para eso estamos. ¿Vienen niños?
Lucía : Sí, mis sobrinos. Uno de tres años y otro de seis.
Rubén : Les pongo una trona para el pequeño.
Lucía : Gracias. Y para el mayor, un cojín, si hay.
Rubén : Hay cojines. Tranquila.
Lucía : Muchas gracias. ¿Qué menú tienen los sábados?
Rubén : Los sábados no hay menú del día. Solo carta.
Lucía : Vale. ¿Qué recomienda?
Rubén : Las croquetas, la tortilla y el cochinillo.
Lucía : ¿Cochinillo? Eso es muy de Segovia, ¿no?
Rubén : Sí, pero aquí lo hacemos muy bien. Mi cocinero es de Cuéllar.
Lucía : Pues apúntame uno para compartir.
Rubén : Un cochinillo para compartir, apuntado.
Lucía : ¿Cuánto cuesta aproximadamente?
Rubén : El cochinillo entero, unos ochenta euros, y da para seis.
Lucía : Vale. Entonces uno entero y algo más.
Rubén : Podemos poner unas croquetas de entrada.
Lucía : Muy bien. ¿Y de postre?
Rubén : Tenemos tarta de queso, natillas y flan casero.
Lucía : A mi abuela le encanta el flan.
Rubén : Le pongo una velita en el flan, si quiere.
Lucía : ¡Qué detalle! Se lo agradezco mucho.
Rubén : Es mi trabajo, no se preocupe.
Lucía : Pues sí, una vela. Y que no se entere.
Rubén : Será una sorpresa. Mis camareros son una tumba.
Lucía : Ja, ja. Confío en ellos.
Rubén : Tienen experiencia con abuelas. Y con abuelos.
Lucía : Perfecto. Oiga, ¿puedo cambiar la hora más adelante?
Rubén : Claro. Pero llámeme con un día de margen.
Lucía : ¿Por qué un día?
Rubén : Para poder mover otras mesas. El sábado vamos llenos.
Lucía : Entiendo. Y si somos nueve, ¿qué hago?
Rubén : Me avisa. Con una persona más cabemos igual.
Lucía : Genial. Y si somos siete, aviso también.
Rubén : Sí, también. Si no, guardo mesa para ocho y se queda sin ocupar.
Lucía : Ah, claro. Me dijo que a veces la gente no aparece.
Rubén : Pasa de vez en cuando. Con ocho personas, más.
Lucía : Pues nosotros seremos puntuales, se lo prometo.
Rubén : Me fío. Su abuela cumple años, ¿no?
Lucía : Setenta. Una bendición.
Rubén : Setenta, enhorabuena. Ojalá yo llegue así.
Lucía : Lo hará, seguro. ¿Y el aparcamiento?
Rubén : Hay un parking público a dos calles de aquí.
Lucía : ¿Cuál es la calle?
Rubén : Calle de la Fuente, número doce. Son cinco minutos andando.
Lucía : Un poco lejos para mi abuela.
Rubén : Si quiere, mis chicos la acompañan hasta la puerta.
Lucía : No quiero molestar.
Rubén : Para nada. Es un placer.
Lucía : Pues agradecida. Entonces, un último repaso.
Rubén : Dígame. Apunto en voz alta.
Lucía : Sábado, a las dos y media.
Rubén : Dos y media. Ocho personas.
Lucía : Mesas juntas. Dos de cuatro.
Rubén : Sí. Una trona, un cojín, rampa de madera.
Lucía : Cochinillo, croquetas, y flan con vela.
Rubén : Eso es. A nombre de Lucía Mora.
Lucía : Y mi teléfono, el seis, uno, cinco...
Rubén : Ya lo tengo. Seis, uno, cinco, dos, tres, cuatro, cuatro, siete, nueve.
Lucía : Perfecto. ¿Y se puede pagar con tarjeta?
Rubén : Sí, con tarjeta, con efectivo y con móvil.
Lucía : ¿Hace falta que cada uno pague por separado?
Rubén : Podemos hacer una sola cuenta o dividirla.
Lucía : Una sola. Mi hermano invita.
Rubén : Qué generoso. ¿Lo sabe él?
Lucía : Todavía no. Se lo diré el sábado.
Rubén : Ja, ja. Valor, hay que tener.
Lucía : Mi hermano siempre invita. Es famoso por eso.
Rubén : Pues que no se asuste con la cuenta.
Lucía : Me aseguraré de que no.
Rubén : Entonces todo listo, señorita Lucía.
Lucía : Todo listo. Muchas gracias, Rubén.
Rubén : ¿Cómo sabe mi nombre?
Lucía : Lo pone en la web. «Rubén, dueño y camarero».
Rubén : Ja, ja. Me ha pillado. Soy yo.
Lucía : Pues encantada. Hasta el sábado.
Rubén : Hasta el sábado. Y feliz cumpleaños a su abuela.
Lucía : Se lo diré de su parte.
Rubén : No, no, que se entere en el flan.
Lucía : Tiene razón. Hasta luego.
Rubén : Hasta luego. Que tengan buen día.
Lucía : Igualmente. Adiós.
Rubén : Adiós, adiós.

## 낭독 포인트
- z/c: «entonces», «cinco», «gracias», «experiencia» — c(e, i)와 z는 [θ](영어 th, thin)로 혀끝을 이 사이에 두고 낸다.
- j/g: «tarjeta», «genial», «juntar», «cojín» — j와 g(e, i)는 강한 [x](목 안쪽에서 나는 h 소리)로 낸다.
- ll/y: «cochinillo», «calle», «natillas», «ya» — ll과 y는 [ʝ](영어 y에 가까운 소리)로 낸다.
- 숫자 읽기: 전화번호는 한 자리씩, 쉬지 말고 또박또박 읽는다(seis, uno, cinco...).
- 억양: 예약 확인(Sábado, a las dos y media)은 리듬 있게 반복한다. 농담(Mis camareros son una tumba)은 가볍게 던진다.
- 호칭: 전화에서는 usted. 끝에서 이름을 서로 알게 되며 부드러워진다.

## 학습 포인트 정리
- B1 구간(1~40, 61~120턴): 전화로 예약하기
  · 시작: «Quería reservar una mesa para el sábado.», «¿Para cuántas personas?», «¿A nombre de quién?»
  · 확인: «Sábado, a las dos y media. Ocho personas.», «Mesas juntas. Dos de cuatro.»
  · 변경: «¿Puedo cambiar la hora más adelante?», «Llámeme con un día de margen.»
  · 부탁: «Le pongo una trona.», «Que no se entere.», «Una vela en el flan.»
- B2 구간(41~60턴): 메뉴와 가격 묻기
  · 추천: «Las croquetas, la tortilla y el cochinillo.», «Da para seis.»
  · 접속법 맛보기: «Ojalá yo llegue así.», «Que no se asuste con la cuenta.»
- 어휘: la reserva, la mesa, la trona, la rampa, la silla de ruedas, el comedor, el cochinillo, la señal, la cuenta.

## 속어 노트
- «Ser una tumba»: 비밀을 잘 지키다(직역 "무덤이다").
- «Quitarse un peso de encima»: 짐을 덜다.
- «Me ha pillado»: 들켰네요.
- «Valor, hay que tener»: 용기가 필요하죠(농담조).
- 가격(코치니요 80유로)과 식당 규칙(보증금 없음)은 이야기 속 설정이다.
- 레지스터 주의: 욕설은 없다.

## 한글 해석
(수요일, 오전 열한 시. 루시아가 집에서 전화한다. 루벤은 타베르나 로스 파라레스의 카운터에서 전화를 받는다. 뒤에서 주방의 웅성거림이 들린다.)
루벤 : 타베르나 로스 파라레스입니다. 말씀하세요.
루시아 : 안녕하세요. 토요일에 자리를 예약하고 싶은데요.
루벤 : 그럼요. 몇 분이세요?
루시아 : 여덟 명이요. 할머니 생신 점심이에요.
루벤 : 좋으시겠어요. 몇 시쯤 오시려고요?
루시아 : 가능하면 두 시 반에요.
루벤 : 예약 장부 좀 볼게요.
루시아 : 네, 천천히 하세요.
루벤 : 여덟 명이면... 그 시간에 큰 탁자가 없네요.
루시아 : 없어요? 아쉽네요.
루벤 : 홀에 네 명 탁자가 두 개 있어요.
루시아 : 붙일 수 있나요?
루벤 : 붙일 수는 있어요. 그런데 좀 좁아요.
루시아 : 우리 가족이면 좁은 게 보통이에요.
루벤 : 하하. 그럼 붙여 드릴게요.
루시아 : 좋아요. 보증금은 내야 하나요?
루벤 : 아뇨, 여덟 명은 보증금을 안 받아요. 전화번호만요.
루시아 : 네. 제 번호를 드릴게요: 육, 일, 오, 이, 삼, 사, 사, 칠, 구.
루벤 : 육, 일, 오, 이, 삼, 사, 사, 칠, 구. 좋아요.
루시아 : 네, 맞아요.
루벤 : 예약은 누구 이름으로 할까요?
루시아 : 루시아 모라 프리에토로 해 주세요.
루벤 : 모라는 r 하나 맞죠?
루시아 : 네, r 하나요. 프리에토는 p로 시작해요.
루벤 : 적었어요. 여덟 명, 토요일, 두 시 반.
루시아 : 알레르기에 대해 하나 물어봐도 될까요?
루벤 : 그럼요. 알레르기 있는 분이 있나요?
루시아 : 삼촌이 견과류를 못 드세요.
루벤 : 적어 둘게요. 주방이 모든 요리에 알려 줘요.
루시아 : 마음이 놓이네요. 고마워요.
루시아 : 하나 더요. 할머니가 휠체어를 쓰세요.
루벤 : 아, 그렇군요. 접이식인가요, 큰 건가요?
루시아 : 접이식이에요. 가벼워요.
루벤 : 그럼 문제없어요. 정문이 넓어요.
루시아 : 계단이 있나요?
루벤 : 하나요, 아주 작은 거예요. 나무 경사로도 있어요.
루시아 : 잘됐네요. 큰 걱정을 덜었어요.
루벤 : 그러라고 있는 거죠. 아이들도 오나요?
루시아 : 네, 조카들요. 세 살짜리와 여섯 살짜리요.
루벤 : 어린 친구에게는 높은 의자를 놓아 드릴게요.
루시아 : 고마워요. 큰 아이에게는 방석도 있으면 좋겠어요.
루벤 : 방석 있어요. 걱정 마세요.
루시아 : 정말 고맙습니다. 토요일에는 어떤 메뉴가 있나요?
루벤 : 토요일에는 오늘의 메뉴가 없어요. 단품 메뉴만 있어요.
루시아 : 알겠어요. 추천해 주실 게 있나요?
루벤 : 크로켓, 토르티야, 새끼 돼지 구이요.
루시아 : 새끼 돼지 구이요? 그건 세고비아 음식 아닌가요?
루벤 : 맞아요, 그래도 여기서도 아주 잘해요. 우리 요리사가 쿠에야르 출신이에요.
루시아 : 그럼 하나는 같이 먹게 적어 주세요.
루벤 : 나눠 드실 새끼 돼지 구이 하나, 적었어요.
루시아 : 대략 얼마쯤 하나요?
루벤 : 한 마리 통째로 팔십 유로쯤이고, 여섯 명이 먹어요.
루시아 : 네. 그럼 한 마리 통째로 하고 조금 더 시킬게요.
루벤 : 애피타이저로 크로켓을 올려 드릴 수 있어요.
루시아 : 좋아요. 디저트는요?
루벤 : 치즈케이크, 나티야스, 집에서 만든 플란이 있어요.
루시아 : 할머니가 플란을 정말 좋아하세요.
루벤 : 원하시면 플란에 초를 꽂아 드릴게요.
루시아 : 정말 세심하시네요! 고마워요.
루벤 : 제 일인걸요. 신경 쓰지 마세요.
루시아 : 그럼 네, 초 하나요. 할머니는 모르게 해 주세요.
루벤 : 깜짝 선물이 될 거예요. 우리 웨이터들은 무덤이에요.
루시아 : 하하. 믿을게요.
루벤 : 할머니, 할아버지 손님 응대 경험이 많아요.
루시아 : 좋아요. 저, 나중에 시간을 바꿔도 될까요?
루벤 : 그럼요. 다만 하루 전에는 전화 주세요.
루시아 : 왜 하루 전이에요?
루벤 : 다른 탁자를 옮겨야 해서요. 토요일엔 만석이에요.
루시아 : 알겠어요. 그럼 아홉 명이 되면 어떻게 하죠?
루벤 : 저에게 알려 주세요. 한 명 더는 그래도 앉을 수 있어요.
루시아 : 좋아요. 일곱 명이 되어도 알릴게요.
루벤 : 네, 그것도요. 안 그러면 여덟 명 자리를 비워 두게 되니까요.
루시아 : 아, 그렇군요. 가끔 사람들이 안 나타난다고 하셨죠.
루벤 : 가끔 그래요. 여덟 명이면 더 그렇고요.
루시아 : 저희는 시간 지킬게요, 약속해요.
루벤 : 믿어요. 할머니 생신이시죠?
루시아 : 칠순이에요. 축복이죠.
루벤 : 칠순, 축하드려요. 저도 그렇게 되면 좋겠네요.
루시아 : 그러실 거예요. 주차는요?
루벤 : 여기서 두 블록 떨어진 곳에 공영 주차장이 있어요.
루시아 : 어느 길이에요?
루벤 : 푸엔테 거리 12번지예요. 걸어서 오 분이에요.
루시아 : 할머니에게는 좀 멀어요.
루벤 : 원하시면 직원들이 문까지 모셔다 드릴게요.
루시아 : 폐를 끼치고 싶지 않아요.
루벤 : 전혀요. 기쁜 일인걸요.
루시아 : 그럼 감사히 받을게요. 마지막으로 한 번 정리할게요.
루벤 : 말씀하세요. 소리 내어 적을게요.
루시아 : 토요일, 두 시 반.
루벤 : 두 시 반. 여덟 명.
루시아 : 탁자 붙이기. 네 명 탁자 두 개.
루벤 : 네. 높은 의자 하나, 방석 하나, 나무 경사로.
루시아 : 새끼 돼지 구이, 크로켓, 그리고 초를 꽂은 플란.
루벤 : 맞아요. 루시아 모라 님 이름으로요.
루시아 : 제 전화번호는 육, 일, 오...
루벤 : 이미 있어요. 육, 일, 오, 이, 삼, 사, 사, 칠, 구.
루시아 : 좋아요. 카드로 결제할 수 있나요?
루벤 : 네, 카드, 현금, 휴대폰 결제 다 돼요.
루시아 : 각자 따로 내야 하나요?
루벤 : 한 번에 계산하셔도 되고 나눠도 돼요.
루시아 : 한 번에요. 오빠가 쏠 거예요.
루벤 : 통이 크시네요. 본인은 아세요?
루시아 : 아직요. 토요일에 말할 거예요.
루벤 : 하하. 용기가 필요하겠네요.
루시아 : 우리 오빠는 늘 쏴요. 그걸로 유명해요.
루벤 : 그럼 계산서에 놀라지 않으면 좋겠네요.
루시아 : 놀라지 않게 신경 쓸게요.
루벤 : 그럼 다 됐네요, 루시아 씨.
루시아 : 다 됐어요. 정말 고마워요, 루벤.
루벤 : 제 이름은 어떻게 아세요?
루시아 : 웹사이트에 나와 있어요. '루벤, 사장 겸 웨이터'라고요.
루벤 : 하하. 들켰네요. 접니다.
루시아 : 반가워요. 토요일에 봬요.
루벤 : 토요일에 봬요. 할머니께 생신 축하드린다고 전해 주세요.
루시아 : 당신 대신 전할게요.
루벤 : 아니, 아니요, 플란으로 알게 하세요.
루시아 : 맞는 말씀이에요. 그럼 이만.
루벤 : 안녕히 계세요. 좋은 하루 보내세요.
루시아 : 그쪽도요. 안녕히 계세요.
루벤 : 네, 안녕히 가세요.
