# 3부 9화. La tortilla de mi abuela (우리 할머니의 토르티야)
난이도: 주 B1 | 구간: B1→B1→A2→B1→B2→B2 | 형식: 2인 대면 | 장소: 카라방첼 할머니 집 부엌 | 시간: 일요일 오전 11시
등장인물: Hugo, Lola
이슈: 주 ○ 노인의 일상과 연금 | 곡선: 1-0-1-0-0-1 (잔잔형, 상한 1) | 입장: 해당 없음(생활 장면. 연금과 혼자 사는 일이 한마디 스침)
상황 카드: 손자 우고가 할머니 롤라에게 토르티야 만드는 법을 배우러 온다. 할머니는 '눈대중으로'만 말하고 분량은 알려 주지 않는다. 걸림돌은 할머니의 감각적인 설명과 우고의 메모. 결말은 첫 토르티야가 뒤집히는 순간과 할머니의 칭찬.
학습 포인트: 요리 순서(Primero, Luego, Después) · 분량 표현(más o menos, a ojo, un poco) · 과거 회상(Cuando era joven…) · 감탄과 칭찬 · 손자와 할머니 사이의 호칭

## 대화
(Domingo, once de la mañana. La cocina de Lola, en Carabanchel. Sobre la encimera hay patatas, huevos, una cebolla y una sartén vieja. Hugo llega con una libreta y un delantal que le queda pequeño.)
Hugo : Hola, abuela. ¡Ya estoy aquí!
Lola : Hola, cariño. Pasa, pasa. Qué guapo vienes.
Hugo : Gracias. Traigo la libreta, como me pediste.
Lola : Ay, qué listo. Pero yo no uso libreta.
Hugo : Por eso, para apuntarlo yo.
Lola : Bueno. Pues siéntate y mira.
Hugo : Primero dime qué ingredientes llevan.
Lola : Patatas, huevos, aceite y sal. Y cebolla, si quieres.
Hugo : ¿Cuántas patatas?
Lola : Pues las que haga falta.
Hugo : Abuela, tienes que decirme un número.
Lola : Cuatro, más o menos. Depende del tamaño.
Hugo : Cuatro patatas medianas. Apunto.
Lola : Y seis huevos. O siete, si son pequeños.
Hugo : Seis o siete huevos. ¿Y el aceite?
Lola : El que necesites para freír las patatas.
Hugo : ¿Cuánto es eso?
Lola : Hasta que casi las cubra. A ojo.
Hugo : Abuela, a ojo no se puede apuntar.
Lola : Pues apunta «a ojo». Y ya está.
Hugo : Vale. «Aceite, a ojo».
Lola : Empezamos. Primero pelamos las patatas.
Hugo : Tomo el pelador.
Lola : Con cuchillo, hijo. El pelador es para turistas.
Hugo : ¿Con cuchillo? Me voy a cortar.
Lola : Con cuidado. Mira cómo lo hago yo.
Hugo : Qué rápido lo haces.
Lola : Cincuenta años de práctica.
Hugo : ¿Y cuántas tortillas has hecho?
Lola : Ay, hijo. Miles. Más de las que te puedas imaginar.
Hugo : ¿Y quién te enseñó?
Lola : Mi madre, tu bisabuela. En un pueblo de Cuenca.
Hugo : ¿También a ojo?
Lola : También a ojo. Y con una sartén de hierro.
Hugo : ¿Esta es la sartén de tu madre?
Lola : Esta misma. Tiene ya noventa años.
Hugo : Ya están peladas. ¿Ahora qué?
Lola : Ahora las cortas en rodajas finas.
Hugo : ¿Cómo de finas?
Lola : Como una moneda. Mejor un poco más gordas.
Hugo : Vale. Como una moneda gorda.
Lola : Eso, eso. Ya lo vas pillando.
Hugo : Abuela, ¿puedo preguntarte una cosa?
Lola : Claro, dime.
Hugo : ¿Por qué cocinas siempre tanto? Vives sola.
Lola : Porque me gusta, cariño. Y porque vienes tú.
Hugo : Pero tienes que comprar todo y pagar la luz...
Lola : Con mi pensión llego. No te preocupes por eso.
Hugo : Si necesitas algo, me lo dices.
Lola : Lo sé, mi niño. Gracias. Pero hoy es día de tortilla.
Hugo : Ya casi termino. ¿Pongo ya la sartén?
Lola : Pon el fuego a media altura. Y echa el aceite.
Hugo : Ya está. Se oye cómo hierve.
Lola : Todavía no. Espera a que haga una burbujita.
Hugo : ¿Una burbujita?
Lola : Sí. Cuando una patata cae y chisporrotea, ya está.
Hugo : Entonces échalas.
Lola : Echa tú. Con cuidado, que salpica.
Hugo : ¿Cuánto tiempo las dejo?
Lola : Hasta que estén blanditas. Unos quince minutos.
Hugo : ¿Quince? Qué lento.
Lola : La cocina es paciencia. Si no, es comida rápida.
Hugo : Entonces apunto «paciencia».
Lola : Apunta «paciencia» y «amor».
Hugo : Mientras esperamos, cuéntame algo.
Lola : ¿Algo de qué?
Hugo : De cuando eras joven. De tu primera tortilla.
Lola : Uy. Mi primera tortilla fue un desastre.
Hugo : ¿Se quemó?
Lola : Se quemó por fuera y estaba cruda por dentro.
Hugo : Ja, ja. ¿Y quién se la comió?
Lola : Tu abuelo. Y dijo que estaba «sabrosa».
Hugo : Qué amor.
Lola : Qué mentiroso. Pero me enamoró.
Hugo : ¿Así de simple?
Lola : Así de simple. Un hombre que se come una tortilla quemada.
Hugo : «Primera tortilla: desastre. Abuelo: la comió».
Lola : Y yo: me casé con él.
Hugo : Me encanta. ¿Y ahora qué?
Lola : Ahora saca las patatas con la espumadera.
Hugo : ¿La espumadera es la cuchara con agujeros?
Lola : Esa. Déjalas escurrir un poco.
Hugo : Ya están. Qué buena pinta.
Lola : Ahora bate los huevos. Con un tenedor.
Hugo : ¿Con las patatas dentro?
Lola : Primero los huevos solos. Y luego mezclas.
Hugo : ¿Y la sal?
Lola : Cuando bates. Una pizca. No te pases.
Hugo : Una pizca. Qué difícil es la cocina.
Lola : No es difícil. Es cuestión de fijarse.
Hugo : Ya está todo mezclado. ¿Y ahora?
Lola : Ahora tiras el aceite sobrante. Dejas un poquito en la sartén.
Hugo : ¿Y vuelco la mezcla?
Lola : Vuelcas y dejas que cuaje. Unos cuatro minutos.
Hugo : Cuatro minutos. Y luego, ¿se da la vuelta?
Lola : Con un plato. Ese es el momento de la verdad.
Hugo : ¿Y si se rompe?
Lola : Si se rompe, es revuelto. Y también está rico.
Hugo : Vale. Con confianza, entonces.
Lola : Pon el plato encima. Con una mano.
Hugo : Así, ¿no?
Lola : Más firme. Y ahora, ¡hop!
Hugo : ¡Ya! ¡Salió entera!
Lola : ¡Bravo, mi niño! Qué orgullo.
Hugo : ¡Mira, abuela! ¡Es una tortilla de verdad!
Lola : Es la mejor que ha salido de esta cocina en años.
Hugo : Entonces la próxima la hago yo solo.
Lola : La próxima me la haces a mí. Que ya estoy mayor.
Hugo : Con mucho gusto. Todos los domingos, si quieres.
Lola : Todos los domingos. Pero con cebolla.
Hugo : Con cebolla, abuela. Prometido.
Lola : Pues a la mesa, que se enfría. Y trae el pan.
Hugo : Ya voy. Y la sidra, ¿la abro?
Lola : Ni se te ocurra. Hoy toca agua con gas.
Hugo : Está bien. Agua con gas y tortilla.
Lola : Qué buena pareja hacen.
Hugo : Igual que tú y el abuelo.
Lola : Anda, calla, que me emociono.
Hugo : Te quiero mucho, abuela.
Lola : Y yo a ti, cariño. Come, que se enfría.

## 낭독 포인트
- z/c: «cebolla», «cincuenta», «cariño», «gracias», «hacer» — [θ]. «Cincuenta»는 [θin-kwén-ta].
- j/g: «jamás», «Cuenca», «gente», «agujeros» — g+e/i와 j는 강한 [x]. «Agujeros»의 g는 부드러운 [ɣ].
- ll/y: «tortilla», «sartén de mi madre», «ya», «yo» — [ʝ]. «Tortilla»는 [tor-tí-ʝa].
- 억양: 할머니의 설명(A ojo)은 느리고 다정하게, 우고의 질문(¿Cuánto es eso?)은 올린다. 뒤집는 순간(¡Hop!)은 숨을 모았다가 터뜨린다.
- 호칭: 손자와 할머니는 tú. 할머니는 'cariño', 'mi niño'를 자주 쓴다.

## 학습 포인트 정리
- B1 구간(1~40, 61~80턴): 요리 순서와 분량
  · 순서: «Primero pelamos las patatas.», «Ahora las cortas en rodajas.», «Luego bates los huevos.»
  · 분량: «Más o menos», «A ojo», «Una pizca», «Las que haga falta».
  · 질문: «¿Cuántas patatas?», «¿Cuánto tiempo las dejo?»
- A2 구간(41~60턴): 단순한 지시
  · 짧은 지시: «Echa tú.», «Con cuidado.», «Espera.»
- B2 구간(81~120턴): 회상과 감정
  · 회상: «Mi primera tortilla fue un desastre.», «Se quemó por fuera y estaba cruda por dentro.»
  · 감정: «Qué orgullo.», «Anda, calla, que me emociono.»
  · 조건: «Si se rompe, es revuelto.»
- 어휘: la tortilla, la patata, la cebolla, el huevo, la sartén, la espumadera, batir, cuajar, la pizca.

## 속어 노트
- «A ojo»: 눈대중으로.
- «Salir entera»: 통째로 잘 나오다(토르티야가 부서지지 않고 뒤집히다).
- «Ni se te ocurra»: 꿈도 꾸지 마라.
- «Mi niño»: 우리 아가(다 큰 손자에게도 쓰는 애정 표현).
- 연금과 생활비 이야기는 이야기 속 설정이다.
- 레지스터 주의: 욕설은 없다.

## 한글 해석
(일요일 오전 열한 시. 카라반첼에 있는 롤라의 부엌. 조리대 위에 감자, 달걀, 양파, 낡은 프라이팬이 있다. 우고가 공책과 작은 앞치마를 가지고 온다.)
우고 : 안녕, 할머니. 나 왔어!
롤라 : 안녕, 아가. 들어와, 들어와. 잘생겼구나.
우고 : 고마워요. 시킨 대로 공책 가져왔어요.
롤라 : 아이고, 똑똑하네. 하지만 난 공책 안 써.
우고 : 그래서 내가 적으려고요.
롤라 : 그래. 그럼 앉아서 봐.
우고 : 먼저 재료부터 말해 주세요.
롤라 : 감자, 달걀, 기름, 소금. 원하면 양파도.
우고 : 감자는 몇 개요?
롤라 : 필요한 만큼.
우고 : 할머니, 숫자를 말해 줘야죠.
롤라 : 네 개쯤. 크기에 따라 달라.
우고 : 중간 크기 감자 네 개. 적었어요.
롤라 : 그리고 달걀 여섯 개. 작으면 일곱 개.
우고 : 달걀 여섯이나 일곱 개. 기름은요?
롤라 : 감자를 튀길 만큼.
우고 : 얼마나요?
롤라 : 감자가 거의 잠길 때까지. 눈대로.
우고 : 할머니, 눈대중은 받아 적을 수 없어요.
롤라 : 그럼 '눈대중'이라고 적어. 그럼 됐지.
우고 : 알겠어요. '기름, 눈대중'.
롤라 : 시작하자. 먼저 감자 껍질을 벗기자.
우고 : 필러 잡을게요.
롤라 : 칼로 하렴, 얘야. 필러는 관광객이나 쓰는 거야.
우고 : 칼로요? 베이겠어요.
롤라 : 조심해서. 내가 하는 걸 봐.
우고 : 정말 빨리 하시네요.
롤라 : 오십 년 연습했으니까.
우고 : 토르티야를 몇 번이나 만드셨어요?
롤라 : 아이고, 수천 번. 상상하는 것보다 많아.
우고 : 누가 가르쳐 줬어요?
롤라 : 내 엄마, 네 증조할머니. 쿠엔카의 시골에서.
우고 : 그때도 눈대중이었어요?
롤라 : 그때도 눈대중. 그리고 쇠 프라이팬으로.
우고 : 이게 증조할머니 프라이팬이에요?
롤라 : 바로 그거야. 벌써 구십 년이야.
우고 : 껍질 다 벗겼어요. 이제 뭐 해요?
롤라 : 이제 얇게 썰어.
우고 : 얼마나 얇게요?
롤라 : 동전처럼. 조금 더 두꺼운 게 낫고.
우고 : 알겠어요. 두꺼운 동전처럼.
롤라 : 그래, 그래. 이제 감 잡네.
우고 : 할머니, 하나 물어봐도 돼요?
롤라 : 그럼, 해 봐.
우고 : 왜 늘 이렇게 많이 요리해요? 혼자 사시는데.
롤라 : 좋아하니까, 아가. 그리고 네가 오니까.
우고 : 그래도 다 사야 하고 전기세도 내야 하잖아요...
롤라 : 연금으로 충분해. 그건 걱정 마.
우고 : 필요한 게 있으면 말해 주세요.
롤라 : 알아, 우리 아가. 고마워. 하지만 오늘은 토르티야 날이야.
우고 : 거의 다 썰었어요. 팬 올릴까요?
롤라 : 불을 중간으로 놓고 기름을 부어.
우고 : 됐어요. 끓는 소리가 나요.
롤라 : 아직 아니야. 작은 거품이 일 때까지 기다려.
우고 : 작은 거품이요?
롤라 : 응. 감자가 떨어지면서 지글거리면 된 거야.
우고 : 그럼 넣을게요.
롤라 : 네가 넣어. 조심해서, 튀니까.
우고 : 얼마나 두어요?
롤라 : 말랑해질 때까지. 한 십오 분.
우고 : 십오 분이요? 느리네요.
롤라 : 요리는 인내야. 아니면 패스트푸드지.
우고 : 그럼 '인내'라고 적을게요.
롤라 : '인내'랑 '사랑'을 적어.
우고 : 기다리는 동안 이야기해 주세요.
롤라 : 무슨 이야기?
우고 : 젊었을 때요. 처음 만든 토르티야요.
롤라 : 아이고. 내 첫 토르티야는 엉망이었어.
우고 : 탔어요?
롤라 : 겉은 타고 속은 덜 익었지.
우고 : 하하. 누가 먹었어요?
롤라 : 네 할아버지. 그리고 '맛있다'고 하더라.
우고 : 사랑스럽네요.
롤라 : 거짓말쟁이지. 그래도 그래서 반했어.
우고 : 그렇게 간단해요?
롤라 : 그렇게 간단해. 탄 토르티야를 먹어 주는 남자.
우고 : '첫 토르티야: 엉망. 할아버지: 먹었다.'
롤라 : 그리고 나: 그와 결혼했다.
우고 : 너무 좋아요. 이제 뭐 해요?
롤라 : 이제 체 숟가락으로 감자를 건져.
우고 : 체 숟가락이 구멍 있는 숟가락이에요?
롤라 : 그거. 조금 물기를 빼 둬.
우고 : 다 됐어요. 보기 좋네요.
롤라 : 이제 달걀을 풀어. 포크로.
우고 : 감자를 넣고요?
롤라 : 먼저 달걀만. 그다음에 섞어.
우고 : 소금은요?
롤라 : 풀 때. 한 꼬집. 넘치지 않게.
우고 : 한 꼬집. 요리는 정말 어렵네요.
롤라 : 어렵지 않아. 잘 보면 돼.
우고 : 다 섞었어요. 이제요?
롤라 : 남은 기름은 버려. 팬에 조금만 남기고.
우고 : 그럼 반죽을 붓나요?
롤라 : 붓고 굳을 때까지 둬. 한 사 분.
우고 : 사 분이요. 그다음에 뒤집나요?
롤라 : 접시로. 그때가 진실의 순간이야.
우고 : 부서지면요?
롤라 : 부서지면 스크램블이야. 그것도 맛있어.
우고 : 알겠어요. 자신 있게 할게요.
롤라 : 접시를 위에 덮어. 한 손으로.
우고 : 이렇게요?
롤라 : 더 단단히. 자, 홉!
우고 : 됐다! 통째로 나왔어요!
롤라 : 브라보, 우리 아가! 자랑스럽다.
우고 : 봐요, 할머니! 진짜 토르티야예요!
롤라 : 몇 년 만에 이 부엌에서 나온 최고야.
우고 : 그럼 다음엔 혼자 만들게요.
롤라 : 다음엔 나한테 만들어 줘. 난 이제 늙었으니까.
우고 : 기꺼이요. 원하시면 일요일마다.
롤라 : 일요일마다. 하지만 양파 넣어서.
우고 : 양파 넣고요, 할머니. 약속해요.
롤라 : 그럼 식탁으로 가, 식는다. 빵도 가져오고.
우고 : 갈게요. 사이다는 열까요?
롤라 : 꿈도 꾸지 마. 오늘은 탄산수야.
우고 : 알겠어요. 탄산수와 토르티야.
롤라 : 참 좋은 짝이구나.
우고 : 할머니와 할아버지처럼요.
롤라 : 그만해, 울컥한다.
우고 : 할머니, 정말 사랑해요.
롤라 : 나도 사랑해, 아가. 먹어, 식는다.
