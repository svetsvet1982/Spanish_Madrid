# 3부 15화. Una caña, por favor (카냐 한 잔 주세요)
난이도: 주 A2 | 구간: B1→A2→B1→B1→A2→B1 | 형식: 2인 대면 | 장소: 후안 카를로스 광장 근처 바 | 시간: 토요일 저녁 8시
등장인물: Emma, Fer
이슈: 주 ○ 외국인 유학생의 언어와 적응 | 곡선: 1-1-1-0-0-1 (반전형, 상한 1) | 입장: 해당 없음(생활 장면. 외국인이라 말이 빨라 못 알아듣는 어려움이 한마디 스침)
상황 카드: 마드리드에 온 지 일주일 된 아일랜드 유학생 엠마가 처음으로 혼자 바에 들어가 카냐를 주문한다. 바텐더 페르는 느리게 말해 주며 카냐, 도블레, 핀초를 설명한다. 걸림돌은 엠마의 어휘와 바텐더의 속도. 결말은 엠마가 두 번째 잔을 스스로 주문하고 단골 인사를 받는 것.
학습 포인트: 바에서 주문하기(Una caña, por favor / Un tinto) · 크기와 종류(caña, doble, tercio) · 가격과 계산 · 재주문과 인사 · 자기소개

## 대화
(Sábado, ocho de la tarde. Un bar de barrio con la barra llena. Emma entra sola, mira la carta de la pared y se acerca. Fer está sirviendo cañas.)
Fer : Buenas tardes. ¿Qué te pongo?
Emma : Hola. Una caña, por favor.
Fer : Una caña, claro. ¿Algo más?
Emma : No, solo la caña. Gracias.
Fer : Enseguida. Siéntate donde quieras.
Emma : ¿Puedo quedarme aquí, en la barra?
Fer : Claro. Es el mejor sitio.
Emma : Gracias. Es mi primera vez.
Fer : ¿Tu primera vez en este bar?
Emma : En un bar de aquí. Llegué hace una semana.
Fer : Ah, entonces bienvenida a Madrid.
Emma : Gracias. Me llamo Emma.
Fer : Encantado, Emma. Yo soy Fer.
Emma : Encantada. ¿Fer es Fernando?
Fer : Sí, Fernando. Pero todos me llaman Fer.
Emma : Vale. Fer. Qué fácil.
Fer : Aquí tienes tu caña.
Emma : Gracias. Es muy pequeña.
Fer : Sí, la caña es pequeña. Tiene unos doscientos mililitros.
Emma : ¿Hay una más grande?
Fer : El doble es el doble de grande. Y el tercio es una botella.
Emma : El doble. Para la próxima.
Fer : Perfecto. ¿De dónde eres?
Emma : De Irlanda. De Dublín.
Fer : Ah, Irlanda. Allí sí sabéis de cerveza.
Emma : Un poco. Pero aquí la cerveza es más ligera.
Fer : Más ligera y más fría.
Emma : Sí, mucho más fría.
Fer : Así se bebe en España. Con calor y con tapas.
Emma : ¿Qué es una tapa?
Fer : Una comida pequeña. Algunos bares la dan con la bebida.
Emma : ¿Gratis?
Fer : A veces sí. Aquí no. Pero tienes pinchos.
Emma : ¿Qué es un pincho?
Fer : Es una tapa con un palillo. Mira, tengo de tortilla y de jamón.
Emma : ¿Cuánto cuesta?
Fer : Dos euros. O dos con cincuenta, el de jamón.
Emma : Quiero el de tortilla.
Fer : Vale, un pincho de tortilla. Aquí tienes.
Emma : Gracias. ¿Cuánto es en total?
Fer : La caña, dos con cincuenta. El pincho, dos. Cuatro con cincuenta.
Emma : Cuatro con cincuenta. Toma.
Fer : (coge el dinero) Cinco euros. Te devuelvo cincuenta céntimos.
Emma : Gracias. Es una moneda grande.
Fer : Sí, la de cincuenta céntimos es grande. La de un euro es más pequeña.
Fer : ¿Cuánto tiempo estás en Madrid?
Emma : Un año. Estudio español en una universidad.
Fer : Qué bien. ¿Y tu español?
Emma : Todavía hablo despacio. Y me cuesta entender.
Fer : Todo el mundo habla muy rápido, ¿verdad?
Emma : Sí. Mucho. Y se come las eses.
Fer : ¿Que se comen las eses? Ja, ja. Es verdad.
Emma : Mi profesora dice que en Andalucía se las comen más.
Fer : Mi familia es de Cádiz, así que sé de lo que hablas.
Emma : Tú no hablas rápido. Te entiendo bien.
Fer : Es que contigo hablo despacio.
Emma : Gracias. Eres muy amable.
Fer : De nada. Pregunta lo que quieras.
Emma : Vale. ¿Cómo se dice «cheers» en español?
Fer : «Salud» o «chin chin». Aquí se dice «salud».
Emma : Salud. Y la respuesta, ¿cuál es?
Fer : Otra vez «salud». O «igualmente».
Emma : Salud, Fer.
Fer : Salud, Emma. Bienvenida.
(Beben. Un cliente pide una cerveza y Fer se la sirve.)
Fer : Perdona. ¿Qué decíamos?
Emma : Que me gusta mucho esta ciudad.
Fer : Me alegro. ¿Qué has visto ya?
Emma : El Retiro, el Museo del Prado y la Plaza Mayor.
Fer : Buen comienzo. ¿Y has comido cocido?
Emma : No. ¿Qué es?
Fer : Un plato de garbanzos con carne y verduras.
Emma : Suena fuerte.
Fer : Lo es. Se come en invierno. Ahora hace calor, mejor otra cosa.
Emma : ¿Qué me recomiendas?
Fer : Unas bravas, que son patatas fritas con salsa.
Emma : ¿Picante?
Fer : Un poco. Si no quieres picante, pides «sin picante».
Emma : Vale. Pido unas bravas, sin picante.
Fer : Marchando. ¿Y otra caña?
Emma : Sí. Un doble, por favor.
Fer : Un doble, ya veo que aprendes rápido.
Emma : Gracias. Un doble y unas bravas.
Fer : Eso, eso. Perfecto.
Emma : Una pregunta más. ¿Dónde está el baño?
Fer : Al fondo, a la izquierda. Detrás de la máquina de tabaco.
(Emma va al baño. Vuelve. Fer ha dejado el doble y un plato de bravas en la barra.)
Fer : Aquí tienes. Un doble y las bravas.
Emma : Qué rápido. Gracias.
Fer : Pruébalas con cuidado. Salen calientes.
Emma : Mmm. Están muy ricas.
Fer : Es la receta de mi madre.
Emma : ¿Trabaja aquí, tu madre?
Fer : No. Ella está en Cádiz. Yo vivo solo en Madrid.
Emma : Como yo. Lejos de casa.
Fer : Sí. Echamos de menos lo mismo.
Emma : A veces, sí. Pero estoy contenta.
Fer : Eso es lo importante. Y siempre tienes este bar.
Emma : Eso me gusta. Volveré.
Fer : Cuando quieras. Estoy de lunes a sábado.
Fer : Oye, ¿quieres que te apunte mi móvil?
Emma : ¿Para qué?
Fer : Para avisarte de los conciertos del barrio. Hay muchos.
Emma : Vale. Me encantaría.
Fer : Tu móvil, ¿cuál es?
Emma : Seis, uno, dos, cuatro, cinco, seis, siete, ocho, nueve.
Fer : Seis, uno, dos, cuatro... ¿cinco?
Emma : Cinco, seis, siete, ocho, nueve.
Fer : Perfecto. Te escribo mañana.
Emma : Genial. Muchas gracias, Fer.
Fer : A ti. Y otra cosa.
Emma : Dime.
Fer : Aquí ya eres de la casa.
Emma : ¿De verdad? ¿Tan rápido?
Fer : Con la segunda caña, ya. Es una regla.
Emma : Gracias. Me hace mucha ilusión.
Fer : Pues entonces la próxima, invito yo.
Emma : No, no. La próxima invito yo.
Fer : Ya veremos. Hasta pronto, Emma.
Emma : Hasta pronto, Fer. Adiós.
Fer : Adiós. Que tengas buena noche.
Emma : Igualmente. Salud.

## 낭독 포인트
- z/c: «gracias», «cincuenta», «cinco», «dice» — c(e, i)와 z는 [θ](영어 th, thin)로 혀끝을 이 사이에 두고 낸다.
- j/g: «ligera», «jamón», «mejor», «trabaja» — j와 g(e, i)는 강한 [x](목 안쪽에서 나는 h 소리)로 낸다.
- ll/y: «tortilla», «botella», «palillo», «ya» — ll과 y는 [ʝ](영어 y에 가까운 소리)로 낸다.
- 억양: 주문(Una caña, por favor)은 또렷하게 올리며, 페르의 설명은 느리고 친절하게. «Salud»는 잔을 부딪치며 밝게.
- 숫자: cuatro con cincuenta(4,50), seis, uno, dos...(전화번호)를 한 자리씩.
- 호칭: 바에서는 tú. 손님과 바텐더가 금방 친해진다.

## 학습 포인트 정리
- B1 구간(1~20, 41~80, 101~120턴): 바 대화와 자기소개
  · 주문: «Una caña, por favor.», «Un doble, por favor.», «Un pincho de tortilla.»
  · 자기소개: «Me llamo Emma.», «Soy de Dublín.», «Llegué hace una semana.»
  · 약속: «La próxima, invito yo.», «Te escribo mañana.»
- A2 구간(21~40, 81~100턴): 크기와 가격
  · 크기: «caña», «doble», «tercio».
  · 가격: «dos con cincuenta», «cuatro con cincuenta», «Te devuelvo cincuenta céntimos.»
  · 질문: «¿Qué es una tapa?», «¿Cuánto cuesta?», «¿Dónde está el baño?»
- 어휘: la caña, el doble, el tercio, el pincho, la tapa, las bravas, la barra, la moneda.

## 속어 노트
- «¿Qué te pongo?»: 뭘 드릴까요? (바에서 쓰는 질문).
- «Marchando»: 나갑니다(주문을 받았다는 신호).
- «Comerse las eses»: s 발음을 삼키다(안달루시아 억양에서 흔하다).
- «Ser de la casa»: 단골이다, 식구나 마찬가지다.
- 가격(카냐 2.50유로)과 바 규칙은 이야기 속 설정이다.
- 레지스터 주의: 욕설은 없다.

## 한글 해석
(토요일 저녁 여덟 시. 카운터가 가득 찬 동네 바. 엠마가 혼자 들어와 벽에 붙은 메뉴판을 보고 다가간다. 페르는 카냐를 따르고 있다.)
페르 : 안녕하세요. 뭘 드릴까요?
엠마 : 안녕하세요. 카냐 한 잔 주세요.
페르 : 카냐요, 알겠어요. 다른 건요?
엠마 : 아니요, 카냐만요. 고마워요.
페르 : 바로 드릴게요. 편한 데 앉아요.
엠마 : 여기 카운터에 있어도 돼요?
페르 : 물론이죠. 제일 좋은 자리예요.
엠마 : 고마워요. 처음이에요.
페르 : 이 바가 처음이에요?
엠마 : 여기 바가 처음이에요. 일주일 전에 왔어요.
페르 : 아, 그럼 마드리드에 온 걸 환영해요.
엠마 : 고마워요. 제 이름은 엠마예요.
페르 : 반가워요, 엠마. 저는 페르예요.
엠마 : 반가워요. 페르가 페르난도예요?
페르 : 네, 페르난도. 그런데 다들 페르라고 불러요.
엠마 : 그렇군요. 페르. 쉽네요.
페르 : 카냐 여기 있어요.
엠마 : 고마워요. 아주 작네요.
페르 : 네, 카냐는 작아요. 이백 밀리리터쯤이에요.
엠마 : 더 큰 건 없어요?
페르 : 도블레는 두 배 크기예요. 그리고 테르시오는 병이에요.
엠마 : 도블레. 다음에 마실게요.
페르 : 좋아요. 어디서 오셨어요?
엠마 : 아일랜드요. 더블린이요.
페르 : 아, 아일랜드. 거기선 맥주를 잘 알죠.
엠마 : 조금요. 하지만 여기 맥주는 더 가벼워요.
페르 : 더 가볍고 더 차갑죠.
엠마 : 네, 훨씬 더 차가워요.
페르 : 스페인에선 그렇게 마셔요. 더울 때, 타파스와 함께.
엠마 : 타파가 뭐예요?
페르 : 작은 요리예요. 어떤 바는 음료와 함께 줘요.
엠마 : 공짜로요?
페르 : 가끔은요. 여긴 아니에요. 하지만 핀초가 있어요.
엠마 : 핀초가 뭐예요?
페르 : 이쑤시개로 꽂은 타파예요. 보세요, 토르티야랑 햄이 있어요.
엠마 : 얼마예요?
페르 : 이 유로요. 햄은 이 유로 오십 센트고요.
엠마 : 토르티야로 할게요.
페르 : 좋아요, 토르티야 핀초. 여기 있어요.
엠마 : 고마워요. 모두 얼마예요?
페르 : 카냐 이 유로 오십, 핀초 이 유로. 사 유로 오십이에요.
엠마 : 사 유로 오십. 여기요.
페르 : (돈을 받는다) 오 유로네요. 오십 센트 거슬러 드릴게요.
엠마 : 고마워요. 동전이 크네요.
페르 : 네, 오십 센트는 커요. 일 유로는 더 작고요.
페르 : 마드리드에는 얼마나 있어요?
엠마 : 일 년이요. 대학교에서 스페인어를 공부해요.
페르 : 좋네요. 스페인어는 어때요?
엠마 : 아직 천천히 말해요. 알아듣기가 힘들어요.
페르 : 다들 아주 빨리 말하죠?
엠마 : 네. 많이요. 그리고 s를 삼켜요.
페르 : s를 삼킨다고요? 하하. 맞아요.
엠마 : 선생님이 안달루시아에선 더 삼킨대요.
페르 : 우리 가족이 카디스 출신이라 무슨 말인지 알아요.
엠마 : 당신은 빠르게 말 안 해요. 잘 알아들어요.
페르 : 당신과 있을 땐 천천히 말하니까요.
엠마 : 고마워요. 정말 친절하네요.
페르 : 별말씀을요. 뭐든 물어봐요.
엠마 : 네. 'cheers'를 스페인어로 뭐라고 해요?
페르 : '살룻' 또는 '친친'이요. 여기선 '살룻'이라고 해요.
엠마 : 살룻. 그럼 대답은요?
페르 : 또 '살룻'. 아니면 '이구알멘테'요.
엠마 : 살룻, 페르.
페르 : 살룻, 엠마. 환영해요.
(둘이 마신다. 한 손님이 맥주를 시키자 페르가 따라 준다.)
페르 : 미안해요. 무슨 얘기하고 있었죠?
엠마 : 이 도시가 정말 마음에 든다는 얘기요.
페르 : 다행이네요. 벌써 뭘 봤어요?
엠마 : 레티로, 프라도 미술관, 마요르 광장이요.
페르 : 좋은 시작이네요. 코시도는 먹어 봤어요?
엠마 : 아니요. 그게 뭐예요?
페르 : 병아리콩에 고기와 채소를 넣은 요리예요.
엠마 : 든든하겠네요.
페르 : 맞아요. 겨울에 먹어요. 지금은 더우니 다른 게 낫죠.
엠마 : 뭘 추천해요?
페르 : 브라바스요. 소스 얹은 감자튀김이에요.
엠마 : 매워요?
페르 : 조금요. 안 매운 걸 원하면 '안 맵게'라고 하세요.
엠마 : 알겠어요. 브라바스 하나, 안 맵게요.
페르 : 나갑니다. 카냐 한 잔 더 하실래요?
엠마 : 네. 도블레로 주세요.
페르 : 도블레라니, 금방 배우네요.
엠마 : 고마워요. 도블레 하나랑 브라바스요.
페르 : 그렇죠. 완벽해요.
엠마 : 하나만 더요. 화장실이 어디예요?
페르 : 안쪽 왼쪽이에요. 담배 자판기 뒤요.
(엠마가 화장실에 간다. 돌아온다. 페르는 카운터에 도블레와 브라바스 접시를 놓아 두었다.)
페르 : 여기 있어요. 도블레와 브라바스예요.
엠마 : 정말 빠르네요. 고마워요.
페르 : 조심해서 먹어 봐요. 뜨거워요.
엠마 : 음. 아주 맛있어요.
페르 : 우리 어머니 레시피예요.
엠마 : 어머니는 여기서 일하세요?
페르 : 아니요. 어머니는 카디스에 계세요. 저는 마드리드에서 혼자 살아요.
엠마 : 저처럼요. 집에서 멀리 떨어져서요.
페르 : 네. 같은 걸 그리워하죠.
엠마 : 가끔은요. 하지만 만족해요.
페르 : 그게 중요해요. 그리고 늘 이 바가 있잖아요.
엠마 : 그게 좋아요. 또 올게요.
페르 : 언제든지요. 월요일부터 토요일까지 있어요.
페르 : 저기, 제 번호를 적어 줄까요?
엠마 : 무슨 용도로요?
페르 : 동네 콘서트 소식을 알려 주려고요. 많아요.
엠마 : 좋아요. 반가워요.
페르 : 번호가 뭐예요?
엠마 : 육, 일, 이, 사, 오, 육, 칠, 팔, 구.
페르 : 육, 일, 이, 사... 오였죠?
엠마 : 오, 육, 칠, 팔, 구.
페르 : 좋아요. 내일 문자 보낼게요.
엠마 : 좋아요. 정말 고마워요, 페르.
페르 : 저야말로요. 그리고 한 가지 더.
엠마 : 말해요.
페르 : 이제 여기 식구예요.
엠마 : 정말요? 이렇게 빨리요?
페르 : 두 번째 카냐부터요. 규칙이에요.
엠마 : 고마워요. 정말 기뻐요.
페르 : 그럼 다음엔 제가 살게요.
엠마 : 아니에요. 다음엔 제가 살게요.
페르 : 두고 봐요. 곧 봐요, 엠마.
엠마 : 곧 봐요, 페르. 안녕히.
페르 : 안녕히. 좋은 밤 보내요.
엠마 : 그쪽도요. 살룻.
