# 5부 1화. Domingo en el Rastro (일요일의 라스트로)
난이도: 주 B1 | 구간: B1→B1→B1→B1→A2→B1 | 형식: 인터뷰 | 장소: 라스트로 벼룩시장 노점 | 시간: 일요일 오전 11시
등장인물: Alba, Fidel
이슈: 주 ◐ 벼룩시장의 관광지화와 노점상의 생계 | 곡선: 2-2-1-0-0-2 (반전형, 상한 2) | 입장: A 피델(사십 년 노점상, 가격이 오르고 관광객이 늘면서 단골이 줄었다) / B 알바(라디오 기자, 시장이 살아남으려면 변해야 하는지 묻는다)
상황 카드: 일요일 아침, 라디오 기자 알바가 라스트로 노점상 피델을 인터뷰한다. 처음엔 시장의 역사와 물건 이야기로 가볍게 시작하지만, 곧 관광객과 임대료, 단속, 후계자 문제로 이야기가 번진다. 걸림돌은 향수와 현실의 간극. 결말은 피델이 "일요일은 아직 일요일"이라고 말하며 알바에게 낡은 라디오를 파는 따뜻한 장면.
학습 포인트: 인터뷰 질문과 대답(¿Desde cuándo…? ¿Qué ha cambiado?) · 과거와 현재 비교(Antes…, Ahora…) · 가격과 흥정 · 시장 어휘(el puesto, el género, el regateo) · 감정이 섞인 회상

## 대화
(Domingo, once de la mañana. La calle Ribera de Curtidores, llena de gente. Alba, con un micrófono y una grabadora, se acerca a un puesto de objetos antiguos. Fidel, con boina, ordena unos relojes sobre una mesa.)
Alba : Buenos días. ¿Puedo hacerle unas preguntas para la radio?
Fidel : Buenos días. ¿Para la radio? Yo no sé hablar bonito.
Alba : No hace falta hablar bonito. Basta con hablar como usted habla.
Fidel : Entonces vale. Pero déjeme terminar con los relojes.
Alba : Claro. Mientras tanto le explico. Soy Alba Rivas, de Radio Madrid.
Fidel : Fidel Márquez. Para servirla.
Alba : Encantada, Fidel. ¿Desde cuándo tiene este puesto?
Fidel : Desde mil novecientos ochenta y cuatro. Cuarenta años largos.
Alba : Cuarenta años. ¿Y cómo empezó?
Fidel : Mi padre vendía chatarra aquí. Yo empecé ayudándole a los quince.
Alba : ¿Se acuerda del primer día?
Fidel : Perfectamente. Vendí una radio de válvulas a un señor de Bilbao.
Alba : ¿Y cuánto le pagó?
Fidel : Quinientas pesetas. Para mí era una fortuna.
Alba : Quinientas pesetas. ¿Cuánto serían ahora?
Fidel : Tres euros, más o menos. Ja, ja. Pero entonces era mucho.
Alba : ¿Y qué vende hoy en su puesto?
Fidel : De todo un poco. Relojes, radios, cámaras antiguas, discos de vinilo.
Alba : ¿Y quién compra eso?
Fidel : Coleccionistas, sobre todo. Y turistas, últimamente.
Alba : ¿Ha cambiado mucho el público?
Fidel : Muchísimo. Antes venían familias de Madrid. Ahora vienen de todo el mundo.
Alba : ¿Eso es bueno o malo?
Fidel : Depende del día. Hay días buenos, con ventas. Y días de solo fotos.
Alba : ¿Solo fotos?
Fidel : Sí. Gente que hace mil fotos y no compra nada.
Alba : Qué frustrante.
Fidel : Un poco. Pero qué se le va a hacer.
Alba : ¿Y los precios? ¿Han subido?
Fidel : Todo ha subido. Las tasas, los alquileres de los almacenes, la gasolina.
Alba : ¿Tiene que pagar algo por el puesto?
Fidel : Sí. La licencia municipal. Se paga cada año.
Alba : ¿Mucho?
Fidel : Unos mil doscientos euros al año. Antes eran seiscientos.
Alba : El doble.
Fidel : Exacto. Y vendemos lo mismo.
Alba : Entiendo. ¿Y el ayuntamiento qué dice?
Fidel : Dice que hay que modernizar el mercado. Con más control.
Alba : ¿Más control de qué?
Fidel : De todo. Horarios, mercancías, licencias... Menos libertad, vamos.
Alba : ¿Le preocupa?
Fidel : Un poco. Pero no me quejo. Cuarenta años da para mucho.
Alba : ¿Y sus hijos? ¿Seguirán con el puesto?
Fidel : Mi hijo no quiere. Es ingeniero. Le gusta más su ordenador.
Alba : ¿Y eso le entristece?
Fidel : Un poco. Pero cada uno tiene su vida.
Alba : ¿Entonces qué pasará con el puesto?
Fidel : No lo sé. Quizá lo cierre. O se lo dé a algún joven que lo quiera.
Alba : ¿Algún joven? ¿Hay alguien interesado?
Fidel : Hay un chico, Mario, que viene mucho a hablar conmigo. Le gusta esto.
Alba : Qué bonito. ¿Le ha ofrecido el puesto?
Fidel : Todavía no. Pero lo estoy pensando.
Alba : Fidel, déjeme hacerle otra pregunta. Más sencilla.
Fidel : Dígame.
Alba : ¿Cuál es su objeto favorito de todo lo que vende?
Fidel : Mire, este reloj. Es de mil novecientos treinta, de bolsillo.
Alba : Es precioso. ¿Funciona?
Fidel : Perfectamente. Le doy cuerda cada mañana.
Alba : ¿Cuánto cuesta?
Fidel : Para usted, noventa euros.
Alba : ¿Y para los demás?
Fidel : Ciento veinte. Pero yo no regateo con las periodistas.
Alba : Ja, ja. Qué amable.
Fidel : Es que usted me cae bien.
Alba : Gracias. Y otra pregunta sencilla: ¿qué desayuna usted antes de venir?
Fidel : Un café con leche y una tostada con aceite. Siempre.
Alba : ¿Y almuerza aquí?
Fidel : En el bar de la esquina, el de Pepe. Un bocadillo de calamares.
Alba : Típico del Rastro.
Fidel : Típico y delicioso. Si viene, le invito.
Alba : Acepto. ¿A qué hora cierra usted?
Fidel : A las tres. Aquí a las tres se acaba el mundo.
Alba : ¿Y después qué hace?
Fidel : A casa, a dormir la siesta. Que ya no tengo veinte años.
Alba : Qué bien. ¿Y los domingos que llueve?
Fidel : Vengo igual. Con un plástico encima de la mesa.
Alba : ¿Siempre viene?
Fidel : Siempre. Solo falté cuando se murió mi mujer. Hace seis años.
Alba : Lo siento mucho.
Fidel : Gracias. Pero aquí me siento acompañado. Todos me conocen.
Alba : ¿Hay una comunidad entre los vendedores?
Fidel : Muy grande. Nos ayudamos. Si uno tiene que irse, los demás vigilan el puesto.
Alba : Qué bonito.
Fidel : Es una familia. Aunque nos peleemos por el sitio.
Alba : ¿Y los clientes de siempre?
Fidel : Cada vez menos. Algunos han muerto. Otros viven lejos.
Alba : ¿Y los nuevos?
Fidel : Los jóvenes vienen mucho. Pero a mirar. Compran poco.
Alba : ¿Por qué?
Fidel : Porque ahora todo se compra por internet, supongo.
Alba : Es verdad. Y usted, ¿vende por internet?
Fidel : Mi nieta me ayudó a hacer una página. Vendo algunas cosas desde casa.
Alba : Qué moderno.
Fidel : Nada de moderno. Me da miedo tocar el ordenador.
Alba : Pero lo hace.
Fidel : Mi nieta me regaña si no lo hago.
Alba : Ja, ja. Bendita nieta.
Fidel : Una bendición.
Alba : Para terminar. ¿Qué le diría a quien nunca ha venido al Rastro?
Fidel : Que venga un domingo, sin prisa. Que mire, que toque, que pregunte.
Alba : ¿Y que compre?
Fidel : Si quiere, sí. Pero lo importante es venir.
Alba : Bonito mensaje. Y una última: ¿qué es el Rastro para usted?
Fidel : Mi casa. La de los domingos.
Alba : Se habla de trasladar el mercado a otro lugar. ¿Qué opina?
Fidel : Que se puede cambiar el sitio, pero no el alma. Y el alma es esta calle.
Alba : ¿Y si lo trasladan?
Fidel : Entonces ya no sería el Rastro. Sería otra cosa con el mismo nombre.
Alba : Qué claro lo dice. Fidel, ¿me vende ese reloj?
Fidel : ¿El de bolsillo? Noventa euros, como le dije.
Alba : Hecho. Pero ahora sin grabadora. ¿Me lo envuelve?
Fidel : Con papel de periódico, que es más del Rastro.
Alba : Perfecto. Gracias, Fidel.
Fidel : A usted. Y vuelva el domingo que viene, que tengo más relojes.
Alba : Volveré. Y le traigo el programa grabado.
Fidel : Pues que sea con música. Una radio sin música no es radio.
Alba : Prometido. Música de los años cuarenta.
Fidel : Eso. Y que se oiga bien.
Alba : Se oirá. Hasta el domingo.
Fidel : Hasta el domingo, Alba.

## 낭독 포인트
- z/c: «hace», «entonces», «gracias», «novecientos» — c(e, i)와 z는 [θ](영어 th, thin)로 혀끝을 이 사이에 두고 낸다.
- j/g: «relojes», «déjeme», «joven», «reloj» — j와 g(e, i)는 강한 [x](목 안쪽에서 나는 h 소리)로 낸다.
- ll/y: «bolsillo», «sencilla», «bocadillo», «yo» — ll과 y는 [ʝ](영어 y에 가까운 소리)로 낸다.
- 억양: 알바의 인터뷰 질문은 부드럽게 올리고, 피델의 대답은 낮고 느리게. 시장의 소음을 배경으로 하듯 약간 큰 목소리로 읽는다. 후반의 걱정(Sería otra cosa con el mismo nombre)은 속도를 늦춘다.
- 가격: noventa euros, ciento veinte, mil doscientos euros, seiscientos를 구별해서 읽는다.
- 호칭: 기자와 노점상은 처음엔 usted, 후반에 이름(Fidel, Alba)을 부른다.

## 학습 포인트 정리
- B1 구간(1~80, 101~120턴): 인터뷰와 회상
  · 인터뷰 질문: «¿Desde cuándo tiene este puesto?», «¿Ha cambiado mucho el público?», «¿Qué es el Rastro para usted?»
  · 과거와 현재: «Antes venían familias de Madrid. Ahora vienen de todo el mundo.», «Antes eran seiscientos. Ahora, mil doscientos.»
  · 감정: «Un poco. Pero qué se le va a hacer.», «Cada uno tiene su vida.»
  · 우려: «Se puede cambiar el sitio, pero no el alma.»
- A2 구간(81~100턴): 흥정
  · 가격과 흥정: «¿Cuánto cuesta?», «Para usted, noventa euros.», «Yo no regateo con las periodistas.»
- 어휘: el puesto, el género, la licencia, el regateo, el coleccionista, la chatarra, el traslado, la boina.

## 속어 노트
- «Para servirla»: 부인을 모시는 사람입니다(격식 있는 인사, 옛 스타일).
- «Qué se le va a hacer»: 어쩌겠어요.
- «Se acaba el mundo»: 세상이 끝난다(여기선 시장이 끝난다는 농담).
- «Hecho»: 좋습니다(거래 성사).
- 노점 허가료, 가격, 이전 논의는 이야기 속 설정이다. 실제 규정과 시장 정책은 최신 정보를 확인해야 한다.
- 레지스터 주의: 욕설은 없다.

## 한글 해석
(일요일 오전 열한 시. 사람들로 가득한 리베라 데 쿠르티도레스 거리. 알바가 마이크와 녹음기를 들고 골동품 노점으로 다가간다. 베레모를 쓴 피델이 탁자에 시계들을 정리하고 있다.)
알바 : 안녕하세요. 라디오를 위해 몇 가지 여쭤봐도 될까요?
피델 : 안녕하세요. 라디오요? 저는 말을 예쁘게 할 줄 몰라요.
알바 : 예쁘게 하실 필요 없어요. 평소 말하는 대로면 돼요.
피델 : 그럼 좋아요. 시계 정리 좀 마저 할게요.
알바 : 그럼요. 그동안 설명드릴게요. 저는 라디오 마드리드의 알바 리바스예요.
피델 : 피델 마르케스예요. 모시겠습니다.
알바 : 반가워요, 피델. 이 노점을 언제부터 하셨어요?
피델 : 천구백팔십사 년부터요. 사십 년 넘었죠.
알바 : 사십 년이요. 어떻게 시작하셨어요?
피델 : 아버지가 여기서 고철을 파셨어요. 저는 열다섯 살에 도우면서 시작했어요.
알바 : 첫날이 기억나세요?
피델 : 똑똑히요. 빌바오 신사분께 진공관 라디오를 팔았어요.
알바 : 얼마에 파셨어요?
피델 : 오백 페세타요. 저한테는 큰돈이었죠.
알바 : 오백 페세타요. 지금으로 치면 얼마쯤일까요?
피델 : 대충 삼 유로요. 하하. 하지만 그땐 큰돈이었어요.
알바 : 지금은 노점에서 뭘 파세요?
피델 : 이것저것요. 시계, 라디오, 오래된 카메라, 엘피판이요.
알바 : 누가 사 가요?
피델 : 주로 수집가들이요. 요즘은 관광객도요.
알바 : 손님층이 많이 변했나요?
피델 : 아주요. 전에는 마드리드 가족들이 왔는데 지금은 전 세계에서 와요.
알바 : 그게 좋은가요, 나쁜가요?
피델 : 날마다 달라요. 파는 날은 좋고, 사진만 찍고 가는 날도 있고요.
알바 : 사진만요?
피델 : 네. 사진은 천 장 찍으면서 하나도 안 사는 사람들이요.
알바 : 속상하시겠어요.
피델 : 조금요. 하지만 어쩌겠어요.
알바 : 가격은요? 올랐나요?
피델 : 다 올랐어요. 세금, 창고 임대료, 기름값.
알바 : 노점에 내는 돈이 있나요?
피델 : 네. 시 허가료예요. 해마다 내요.
알바 : 많이요?
피델 : 일 년에 천이백 유로쯤요. 전에는 육백이었어요.
알바 : 두 배네요.
피델 : 맞아요. 그런데 파는 건 똑같아요.
알바 : 알겠어요. 시청은 뭐라고 하나요?
피델 : 시장을 현대화해야 한대요. 통제를 더 하면서요.
알바 : 뭘 더 통제해요?
피델 : 다요. 시간, 물건, 허가... 자유는 줄어든다는 소리죠.
알바 : 걱정되세요?
피델 : 조금요. 하지만 불평은 안 해요. 사십 년이면 많은 일이 있어요.
알바 : 자녀분은요? 노점을 이어받을까요?
피델 : 아들은 안 원해요. 엔지니어예요. 컴퓨터를 더 좋아해요.
알바 : 서운하세요?
피델 : 조금요. 하지만 각자 인생이 있죠.
알바 : 그럼 노점은 어떻게 될까요?
피델 : 모르겠어요. 닫을 수도 있고, 원하는 젊은이에게 줄 수도 있고요.
알바 : 젊은이요? 관심 있는 사람이 있나요?
피델 : 마리오라는 청년이 자주 와서 저랑 얘기해요. 이런 걸 좋아해요.
알바 : 멋지네요. 노점을 제안하셨어요?
피델 : 아직요. 하지만 생각 중이에요.
알바 : 피델, 좀 더 쉬운 질문을 해도 될까요?
피델 : 말씀하세요.
알바 : 파시는 물건 중에 제일 좋아하는 게 뭐예요?
피델 : 이 시계요. 천구백삼십 년 거 회중시계예요.
알바 : 정말 예뻐요. 작동해요?
피델 : 완벽하게요. 매일 아침 태엽을 감아요.
알바 : 얼마예요?
피델 : 부인께는 구십 유로요.
알바 : 다른 분들께는요?
피델 : 백이십이요. 하지만 기자분께는 깎아 주지 않아요.
알바 : 하하. 친절하시네요.
피델 : 마음에 들어서요.
알바 : 고마워요. 쉬운 질문 하나 더요, 오시기 전에 아침은 뭘 드세요?
피델 : 카페 콘 레체랑 올리브유 토스트요. 늘요.
알바 : 점심은 여기서 드세요?
피델 : 모퉁이 바, 페페네에서요. 오징어 샌드위치요.
알바 : 라스트로다운 메뉴네요.
피델 : 라스트로답고 맛있죠. 오시면 제가 낼게요.
알바 : 받을게요. 몇 시에 닫으세요?
피델 : 세 시요. 여기선 세 시에 세상이 끝나요.
알바 : 그 뒤엔 뭘 하세요?
피델 : 집에 가서 낮잠이요. 이제 스무 살이 아니니까요.
알바 : 좋네요. 비 오는 일요일은요?
피델 : 그래도 와요. 탁자 위에 비닐을 씌우고요.
알바 : 늘 나오세요?
피델 : 늘요. 아내가 세상을 떠났을 때만 빠졌어요. 육 년 전에요.
알바 : 마음이 아프네요.
피델 : 고마워요. 하지만 여기선 외롭지 않아요. 다 저를 알아요.
알바 : 상인들 사이에 공동체가 있나요?
피델 : 아주 커요. 서로 도와요. 누가 자리를 비우면 다른 사람이 노점을 봐 줘요.
알바 : 멋지네요.
피델 : 가족이에요. 자리 때문에 싸우기도 하지만요.
알바 : 오랜 단골 손님은요?
피델 : 점점 줄어요. 돌아가신 분도 있고 멀리 사는 분도 있고요.
알바 : 새 손님들은요?
피델 : 젊은이들이 많이 와요. 하지만 구경하러요. 거의 안 사요.
알바 : 왜일까요?
피델 : 요즘은 다 인터넷으로 사니까요.
알바 : 맞아요. 피델은 인터넷으로 파세요?
피델 : 손녀가 홈페이지를 만들어 줬어요. 집에서 몇 가지 팔아요.
알바 : 현대적이시네요.
피델 : 현대적은 무슨. 컴퓨터 만지는 게 무서운데.
알바 : 그래도 하시잖아요.
피델 : 안 하면 손녀가 혼내요.
알바 : 하하. 복받은 손녀네요.
피델 : 축복이에요.
알바 : 마무리 질문이에요. 라스트로에 와 본 적 없는 분께 뭐라고 하시겠어요?
피델 : 일요일에 서두르지 말고 오라고요. 보고, 만지고, 물어보라고요.
알바 : 그리고 사라고요?
피델 : 원하면요. 하지만 중요한 건 오는 거예요.
알바 : 멋진 메시지네요. 마지막으로, 피델에게 라스트로는 뭐예요?
피델 : 제 집이에요. 일요일의 집.
알바 : 시장을 다른 곳으로 옮기자는 얘기도 있어요. 어떻게 생각하세요?
피델 : 장소는 바꿀 수 있어도 영혼은 못 바꿔요. 그리고 영혼은 이 거리예요.
알바 : 옮기면요?
피델 : 그럼 더는 라스트로가 아니죠. 이름만 같은 다른 곳이 될 거예요.
알바 : 참 분명하게 말씀하시네요. 피델, 그 시계 파시겠어요?
피델 : 회중시계요? 말씀드린 대로 구십 유로예요.
알바 : 좋아요. 하지만 녹음기는 끄고요. 포장해 주시겠어요?
피델 : 신문지로요. 그게 더 라스트로답죠.
알바 : 완벽해요. 고마워요, 피델.
피델 : 저야말로요. 다음 일요일에 또 오세요, 시계가 더 있어요.
알바 : 올게요. 녹음한 프로그램도 가져올게요.
피델 : 음악도 넣어 주세요. 음악 없는 라디오는 라디오가 아니죠.
알바 : 약속해요. 사십 년대 음악으로요.
피델 : 그거예요. 그리고 잘 들리게 해 주세요.
알바 : 잘 들릴 거예요. 일요일에 봬요.
피델 : 일요일에 봐요, 알바.
