# 5부 3화. Fútbol en el parque (공원 축구)
난이도: 주 A2 | 구간: A2→B1→A2→A2→A2→A2 | 형식: 다인(4명) | 장소: 카사 데 캄포 공원 잔디밭 | 시간: 일요일 오전 11시
등장인물: Rafa, Samir, Julia, Leo
이슈: 주 ○ 공공 공간 이용과 동네 스포츠 | 곡선: 0-0-1-1-1-0 (잔잔형, 상한 1) | 입장: 해당 없음(생활 장면. 공공 축구장이 부족하다는 말이 한마디 스침)
상황 카드: 일요일 아침 공원에서 친구들이 축구를 한다. 팀을 나누고, 규칙을 정하고, 득점하고, 물을 마시며 쉰다. 걸림돌은 선수 수가 모자라는 것과 공이 나무 뒤로 날아가는 일. 결말은 점수를 정확히 세지 않은 채 같이 점심을 먹으러 가자고 하는 것.
학습 포인트: 축구 어휘(el balón, la portería, el gol, el árbol, pasar) · 팀 나누기와 포지션 · 점수와 숫자 · 짧은 지시(Pasa, Corre, Tira) · 제안과 초대

## 대화
(Domingo, once de la mañana. Un campo de césped en la Casa de Campo, con dos porterías hechas de mochilas. Rafa llega con un balón bajo el brazo. Samir, Julia y el pequeño Leo le esperan.)
Rafa : ¡Buenos días a todos!
Samir : Buenas, Rafa. ¡Llegas tarde!
Rafa : Solo cinco minutos. Había mucho tráfico.
Julia : Hola, Rafa. ¿Trajiste el balón?
Rafa : Claro que sí. Mira, es nuevo.
Leo : ¡Qué bonito! ¿Puedo tocarlo?
Rafa : Claro, Leo. Pero con cuidado.
Leo : Vale. ¡Es muy suave!
Samir : Bueno, ¿empezamos?
Julia : Somos cuatro. Dos contra dos.
Rafa : Perfecto. ¿Cómo hacemos los equipos?
Samir : Yo y Leo contra Rafa y Julia.
Julia : Pero Leo es pequeño. Es injusto.
Samir : Leo es muy rápido. Ya verás.
Leo : ¡Sí! ¡Soy muy rápido!
Rafa : Vale, vale. Samir y Leo, el equipo rojo.
Julia : Rafa y yo, el azul.
Samir : ¿Dónde están las porterías?
Rafa : Mira. Esas dos mochilas, allí. Y las otras dos, aquí.
Julia : ¿Cuántos goles para ganar?
Rafa : El primero que llegue a cinco gana.
Samir : Cinco goles. Perfecto.
Leo : ¡Vamos a ganar!
Julia : Ja, ja. Eso lo veremos.
Rafa : Samir, saca tú.
Samir : Vale. ¡Allá voy!
(Empiezan a jugar. Corren por el césped. El balón rueda.)
Samir : ¡Leo, pasa!
Leo : ¡Toma!
Samir : ¡Bien! ¡Corre!
Julia : ¡Rafa, ayuda!
Rafa : ¡Voy, voy!
Samir : ¡Tiro!
Rafa : ¡Casi!
Julia : ¡Uy! El balón está fuera.
Rafa : Voy yo. Está detrás del árbol.
Leo : ¡Cuidado, Rafa! Hay una piedra.
Rafa : Gracias, Leo. ¡Ya lo tengo!
Julia : ¡Saca de banda!
Rafa : Voy. ¡Pasa, Julia!
Julia : ¡Toma! Ahora tú, Rafa.
Rafa : ¡Tiro! ¡Gol!
Julia : ¡Uno a cero!
Samir : ¡Eso no vale! Estaba en fuera de juego.
Rafa : ¿Fuera de juego? Aquí no hay fuera de juego.
Samir : Siempre hay fuera de juego.
Julia : No, no. Eso es para los profesionales.
Samir : Vale. Gol. Pero luego no hay fuera de juego para nadie.
Rafa : Trato hecho.
Leo : Papá dice que el fuera de juego es muy difícil.
Julia : ¿Tu papá juega al fútbol?
Leo : Sí. Juega en un equipo del barrio.
Rafa : Qué bien. ¿Y tú? ¿Quieres jugar en un equipo?
Leo : Sí, pero tengo que esperar. Solo tengo siete años.
Samir : Dentro de un año puedes entrar en uno.
Leo : Vale. Estoy esperando.
Julia : ¿Seguimos?
Samir : Seguimos. Uno a cero. ¡Saco yo!
(Siguen jugando. Un rato después, Samir marca un gol.)
Samir : ¡Gol! ¡Uno a uno!
Leo : ¡Sí! ¡Hemos metido un gol!
Julia : Muy bien, Leo. Qué buen pase.
Leo : Gracias. ¡Mira, Samir! ¡Choca esos cinco!
Samir : ¡Toma! ¡Vamos, equipo rojo!
Rafa : Ya, ya. Que todavía no hemos terminado.
Julia : Rafa, ¿tienes sed?
Rafa : Muchísima. Hace mucho calor.
Julia : Yo traje agua. ¿Quieres un poco?
Rafa : Sí, por favor.
Julia : Toma. Y para ti, Samir. Y para Leo.
Leo : Gracias, Julia. Está muy fría.
Samir : Perfecto. Un descanso corto, ¿vale?
Rafa : Cinco minutos. Luego seguimos.
Julia : Qué bien se está aquí.
Rafa : Sí. Es un parque muy grande.
Julia : ¿Venís aquí cada domingo?
Rafa : Casi todos. Es el único sitio que tenemos.
Samir : Es verdad. Hay pocos campos gratis en el barrio.
Julia : ¿Pocos? ¿Y el campo del colegio?
Samir : Está cerrado los fines de semana. Hay que pedir permiso.
Julia : Qué pena. Así no se puede jugar.
Rafa : Por eso venimos aquí. No es perfecto, pero es de todos.
Leo : A mí me gusta. Hay árboles.
Rafa : Ja, ja. Y mucho césped.
Samir : A mí me gustan los patos del lago.
Julia : ¿Hay un lago aquí cerca?
Rafa : Sí, a diez minutos andando. Podemos ir después.
Leo : ¡Sí! ¡Quiero ver los patos!
Julia : Vale. Primero comemos, luego los patos.
Samir : Plan perfecto. Pero primero, el partido.
Julia : Bueno. ¿Seguimos?
Samir : Seguimos. Uno a uno. ¡Saca Rafa!
(Siguen jugando. El balón sale volando entre los árboles.)
Leo : ¡Ay, no! ¡El balón!
Samir : Voy a buscarlo.
Julia : Te ayudo. A ver, ¿dónde está?
Rafa : Allí, junto al banco. ¡Mirad!
Samir : ¡Lo veo! ¡Ya lo tengo!
Leo : ¡Qué bien! Casi se pierde.
Julia : Menos mal. Es nuevo.
Rafa : Y caro. Me costó veinte euros.
Samir : Pues cuídalo. Y no tires tan fuerte.
Rafa : Vale, vale. A partir de ahora, tiro suave.
Julia : Mejor. Seguimos.
(Siguen jugando. Pasan unos minutos. Se oye el sonido de una campana lejana.)
Samir : Son las doce y media. ¡Qué rápido!
Julia : ¿Cuánto vamos?
Rafa : No lo sé. Creo que cuatro a tres.
Julia : Yo creo que tres a tres.
Leo : Yo creo que ganamos.
Samir : Ja, ja. Nadie lo sabe. Mejor un empate.
Rafa : Un empate, vale. Y ahora, ¿comemos algo?
Julia : Sí. Tengo hambre. ¿Vamos al bar del parque?
Samir : Perfecto. Yo invito a unas bebidas.
Leo : ¡Yo quiero un helado!
Samir : Claro, Leo. Un helado para el campeón.
Leo : ¡Viva!
Rafa : Ja, ja. Vamos, equipo.
Julia : Vamos. Y el domingo que viene, revancha.
Samir : Revancha. Pero con fuera de juego.
Rafa : ¡Ni hablar! Sin fuera de juego.
Leo : ¡Sin fuera de juego! ¡Sin fuera de juego!
Julia : Ja, ja. Ganó Leo.
Samir : Ganó Leo. Vamos.

## 낭독 포인트
- z/c: «cinco», «gracias», «cero», «empezamos» — c(e, i)와 z는 [θ](영어 th, thin)로 혀끝을 이 사이에 두고 낸다.
- j/g: «juego», «jugar», «mejor», «rojo» — j와 g(e, i)는 강한 [x](목 안쪽에서 나는 h 소리)로 낸다.
- ll/y: «allí», «llegas», «allá», «yo» — ll과 y는 [ʝ](영어 y에 가까운 소리)로 낸다.
- 억양: 경기 중 짧은 외침(¡Pasa! ¡Tira! ¡Gol!)은 크고 빠르게, 쉬는 시간 대화는 느리고 편하게. 레오의 대사는 아이답게 밝게 읽는다.
- 숫자: uno a cero, uno a uno, cuatro a tres, tres a tres를 점수 읽듯 또박또박.
- 호칭: 친구와 아이 사이라 tú와 vosotros(¿Venís aquí cada domingo?, ¡Mirad!).

## 학습 포인트 정리
- A2 구간(1~20, 41~120턴): 경기와 일상
  · 팀과 규칙: «Yo y Leo contra Rafa y Julia.», «El primero que llegue a cinco gana.», «Aquí no hay fuera de juego.»
  · 지시: «¡Pasa!», «¡Corre!», «¡Tiro!», «Saca de banda.»
  · 점수: «Uno a cero.», «Uno a uno.», «Tres a tres.», «Un empate.»
  · 제안: «¿Seguimos?», «¿Vamos al bar del parque?», «Un helado para el campeón.»
- B1 구간(21~40턴): 규칙 논쟁
  · 의견: «Eso no vale.», «Eso es para los profesionales.», «Trato hecho.»
- 공공 공간: «Hay pocos campos gratis en el barrio.», «Por eso venimos aquí. No es perfecto, pero es de todos.»
- 어휘: el balón, la portería, el gol, el árbol, el césped, el banco, el empate, la revancha.

## 속어 노트
- «Choca esos cinco»: 하이파이브 하자.
- «Menos mal»: 다행이다.
- «Un empate»: 무승부.
- «No vale»: 인정 안 돼, 반칙이야.
- 점수와 시간은 이야기 속 설정이다. 공공 축구장 이용 규정은 지역마다 다르다.
- 레지스터 주의: 욕설은 없다.

## 한글 해석
(일요일 오전 열한 시. 카사 데 캄포의 잔디밭, 배낭으로 만든 골대 두 개. 라파가 공을 옆구리에 끼고 도착한다. 사미르, 훌리아, 어린 레오가 기다리고 있다.)
라파 : 다들 안녕!
사미르 : 안녕, 라파. 늦었네!
라파 : 오 분밖에 안 늦었어. 길이 막혔어.
훌리아 : 안녕, 라파. 공 가져왔어?
라파 : 물론이지. 봐, 새 거야.
레오 : 와, 예쁘다! 만져 봐도 돼요?
라파 : 그럼, 레오. 조심해서.
레오 : 네. 아주 부드러워요!
사미르 : 자, 시작할까?
훌리아 : 우리 넷이야. 둘 대 둘.
라파 : 좋아. 팀은 어떻게 나눌까?
사미르 : 나랑 레오 대 라파랑 훌리아.
훌리아 : 하지만 레오는 작잖아. 불공평해.
사미르 : 레오는 아주 빨라. 두고 봐.
레오 : 네! 저 정말 빨라요!
라파 : 좋아, 좋아. 사미르와 레오가 레드 팀.
훌리아 : 라파와 내가 블루 팀.
사미르 : 골대는 어디야?
라파 : 봐. 저기 배낭 두 개. 그리고 이쪽에 두 개.
훌리아 : 몇 골이면 이겨?
라파 : 먼저 다섯 골 넣는 쪽이 이겨.
사미르 : 다섯 골. 좋아.
레오 : 우리가 이길 거야!
훌리아 : 하하. 두고 보자.
라파 : 사미르, 네가 시작해.
사미르 : 알았어. 간다!
(경기를 시작한다. 잔디 위를 달린다. 공이 구른다.)
사미르 : 레오, 패스!
레오 : 받아요!
사미르 : 좋아! 뛰어!
훌리아 : 라파, 도와줘!
라파 : 간다, 간다!
사미르 : 슛!
라파 : 아깝다!
훌리아 : 어머! 공이 밖으로 나갔어.
라파 : 내가 갈게. 나무 뒤에 있어.
레오 : 조심해요, 라파! 돌이 있어요.
라파 : 고마워, 레오. 잡았다!
훌리아 : 스로인!
라파 : 간다. 패스, 훌리아!
훌리아 : 받아! 이제 라파.
라파 : 슛! 골!
훌리아 : 일 대 영!
사미르 : 그건 안 돼! 오프사이드였어.
라파 : 오프사이드? 여기엔 오프사이드 없어.
사미르 : 오프사이드는 늘 있어.
훌리아 : 아니야. 그건 프로 선수들 얘기야.
사미르 : 좋아. 골 인정. 하지만 그럼 누구에게도 오프사이드 없는 거야.
라파 : 약속.
레오 : 아빠가 오프사이드는 아주 어렵대요.
훌리아 : 아빠가 축구하셔?
레오 : 네. 동네 팀에서 뛰어요.
라파 : 멋지네. 너는? 팀에서 뛰고 싶어?
레오 : 네, 하지만 기다려야 해요. 이제 일곱 살이라서요.
사미르 : 일 년 뒤면 들어갈 수 있어.
레오 : 알겠어요. 기다리는 중이에요.
훌리아 : 계속할까?
사미르 : 계속하자. 일 대 영. 내가 시작할게!
(계속 경기한다. 잠시 후 사미르가 골을 넣는다.)
사미르 : 골! 일 대 일!
레오 : 와! 우리가 골 넣었어!
훌리아 : 잘했어, 레오. 패스 좋았어.
레오 : 고마워요. 사미르 형, 하이파이브!
사미르 : 받아! 가자, 레드 팀!
라파 : 알았어, 알았어. 아직 안 끝났어.
훌리아 : 라파, 목말라?
라파 : 엄청. 너무 더워.
훌리아 : 난 물 가져왔어. 좀 마실래?
라파 : 응, 부탁해.
훌리아 : 자. 사미르도 마셔. 레오도.
레오 : 고마워요, 훌리아 누나. 아주 차가워요.
사미르 : 좋아. 잠깐 쉴까, 어때?
라파 : 오 분. 그다음에 계속하자.
훌리아 : 여기 있으니 참 좋다.
라파 : 응. 아주 큰 공원이야.
훌리아 : 매주 일요일에 와?
라파 : 거의 매번. 우리가 쓸 수 있는 유일한 곳이야.
사미르 : 맞아. 동네에 무료 운동장이 적어.
훌리아 : 적다고? 학교 운동장은?
사미르 : 주말엔 닫아. 허락을 받아야 해.
훌리아 : 아쉽다. 그러면 못 놀겠네.
라파 : 그래서 여기 와. 완벽하진 않지만 모두의 곳이야.
레오 : 나는 좋아요. 나무가 있어요.
라파 : 하하. 그리고 잔디도 많고.
사미르 : 나는 호수의 오리가 좋아.
훌리아 : 근처에 호수가 있어?
라파 : 응, 걸어서 십 분. 이따 가자.
레오 : 네! 오리 보고 싶어요!
훌리아 : 좋아. 먼저 밥을 먹고 그다음에 오리야.
사미르 : 완벽한 계획이야. 하지만 먼저 경기부터.
훌리아 : 자, 계속할까?
사미르 : 계속하자. 일 대 일. 라파가 시작해!
(계속 경기한다. 공이 나무 사이로 날아간다.)
레오 : 아이고! 공이!
사미르 : 내가 찾으러 갈게.
훌리아 : 도와줄게. 어디 있지?
라파 : 저기, 벤치 옆이야. 봐!
사미르 : 보인다! 잡았다!
레오 : 다행이에요! 잃어버릴 뻔했어요.
훌리아 : 다행이야. 새 공인데.
라파 : 그리고 비싸. 이십 유로 줬어.
사미르 : 그럼 아껴 써. 그리고 너무 세게 차지 마.
라파 : 알았어, 알았어. 지금부터 살살 찰게.
훌리아 : 그게 낫다. 계속하자.
(계속 경기한다. 몇 분이 지난다. 멀리서 종소리가 들린다.)
사미르 : 열두 시 반이야. 정말 빠르다!
훌리아 : 몇 대 몇이야?
라파 : 몰라. 사 대 삼일걸.
훌리아 : 난 삼 대 삼이라고 생각해.
레오 : 저는 우리가 이겼다고 생각해요.
사미르 : 하하. 아무도 모르지. 그냥 무승부로 하자.
라파 : 무승부, 좋아. 이제 뭐 좀 먹을까?
훌리아 : 응. 배고파. 공원 바에 갈까?
사미르 : 좋아. 음료는 내가 살게.
레오 : 저는 아이스크림 먹고 싶어요!
사미르 : 그럼, 레오. 챔피언에게 아이스크림.
레오 : 만세!
라파 : 하하. 가자, 팀.
훌리아 : 가자. 그리고 다음 일요일엔 복수전.
사미르 : 복수전. 하지만 오프사이드 있게.
라파 : 말도 안 돼! 오프사이드 없이!
레오 : 오프사이드 없이! 오프사이드 없이!
훌리아 : 하하. 레오가 이겼네.
사미르 : 레오가 이겼다. 가자.
