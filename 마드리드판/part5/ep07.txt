# 5부 7화. Un paseo por el Retiro (레티로 공원 산책)
난이도: 주 A2 | 구간: A2→B1→B1→A2→B1→A2 | 형식: 2인 | 장소: 레티로 공원 산책로와 연못 | 시간: 일요일 오후 4시
등장인물: Inma, Tariq, Heladero
이슈: 주 ○ 도시 공원과 여가 | 곡선: 0-1-1-0-1-0 (잔잔형, 상한 1) | 입장: 해당 없음(생활 장면. 관광객이 많아졌다는 말이 한마디 스침)
상황 카드: 마드리드에 사는 인마가 모로코에서 온 사촌 타리크에게 레티로 공원을 안내한다. 정문, 큰 연못, 크리스털 궁전, 아이스크림, 벤치에서의 휴식을 거치는 느린 산책이다. 걸림돌은 길과 어휘. 결말은 해 질 무렵 연못에서 보트를 타기로 하는 것.
학습 포인트: 장소 소개(Mira, aquí está…) · 방향(a la derecha, todo recto) · 날씨와 계절 · 제안(¿Quieres…? ¿Te apetece…?) · 간단한 과거(Ayer fui…)

## 대화
(Domingo, cuatro de la tarde. La puerta de Alcalá y la entrada del Retiro. Inma espera con una botella de agua. Tariq llega con una gorra y una cámara.)
Inma : ¡Tariq! ¡Por aquí!
Tariq : ¡Inma! Perdona, he tardado.
Inma : No pasa nada. ¿Cómo estás?
Tariq : Muy bien. Pero hace calor.
Inma : Sí. Hoy hay treinta grados.
Tariq : Treinta. En mi ciudad hace menos.
Inma : Pero aquí vamos a estar a la sombra. Mira.
Tariq : ¡Cuántos árboles! Es enorme.
Inma : Sí. El Retiro tiene más de ciento veinte hectáreas.
Tariq : ¿Hectáreas? ¿Eso es mucho?
Inma : Mucho. Como ciento cincuenta campos de fútbol.
Tariq : Qué grande. ¿Podemos verlo todo?
Inma : Todo no. Pero lo más bonito, sí.
Tariq : Vale. Vamos.
Inma : Entramos por esta puerta. Es la puerta de España.
Tariq : Qué bonita. ¿Es antigua?
Inma : Sí. Más o menos de hace doscientos años.
Tariq : Doscientos años. Y sigue aquí.
Inma : Sí. El parque fue de los reyes. Ahora es de todos.
Tariq : Qué bien. Es gratis, ¿verdad?
Inma : Sí, entrar es gratis. Solo pagas si quieres ir en barca.
Tariq : ¿Hay barcas?
Inma : Sí. En el estanque grande. Ya lo verás.
Tariq : ¿Es lejos?
Inma : No. Dos minutos andando. Todo recto.
Tariq : Todo recto. Vamos.
(Caminan por un paseo ancho con árboles altos. Pasan unos ciclistas. Hay un músico tocando la guitarra.)
Tariq : ¡Mira! Un hombre toca la guitarra.
Inma : Sí. En el Retiro siempre hay música.
Tariq : Qué ambiente. Me gusta.
Inma : A mí también. Vengo casi todos los domingos.
Tariq : ¿Con tus amigos?
Inma : A veces con amigos, a veces sola con un libro.
Tariq : ¿Y qué lees?
Inma : Ahora, una novela de misterio. Se llama «La sombra del jardín».
Tariq : Qué título tan bonito. ¿Es buena?
Inma : Muy buena. Si quieres, te la presto.
Tariq : Gracias, pero mi español no es suficiente.
Inma : Lo hablas muy bien. No te preocupes.
Tariq : Gracias. Pero leer es más difícil.
Inma : Poco a poco. Mira, aquí a la derecha, el estanque.
Tariq : ¡Qué grande! ¡Y cuánta gente!
Inma : Sí. En verano viene mucha gente. Hay barcas de colores.
Tariq : Y un monumento enorme.
Inma : Es el monumento a Alfonso XII. Mira cómo brilla al sol.
Tariq : Sí, es precioso. Voy a sacar una foto.
Inma : Claro. Tienes que ponerte por aquí, con el agua detrás.
Tariq : ¿Así?
Inma : Un poco más a la izquierda. Perfecto.
Tariq : (hace la foto) Ya está. Ahora tú.
Inma : No, no. Yo ya tengo muchas.
Tariq : Por favor. Una sola.
Inma : Vale. Una sola. Pero rápido.
Tariq : Uno, dos, tres. Sonríe.
Inma : Ja, ja. Qué horror de cara.
Tariq : Estás perfecta.
Inma : Mentiroso. Vamos.
(Caminan por el borde del estanque. Hay gente en barcas. Una pareja se hace fotos.)
Tariq : ¿Por qué hay tantos turistas?
Inma : Porque es muy famoso. Y es verano.
Tariq : ¿Eso te molesta?
Inma : A veces. Pero me gusta que venga gente de todo el mundo.
Tariq : A mí también. Yo soy turista.
Inma : No, tú eres mi primo. Eso es distinto.
Tariq : Ja, ja. Gracias.
Inma : Mira, ahora a la izquierda. Allí está el Palacio de Cristal.
Tariq : ¿El qué?
Inma : El Palacio de Cristal. Es un edificio todo de vidrio.
Tariq : ¡Qué bonito! Parece una joya.
Inma : Sí. Es del siglo diecinueve. Lo hicieron para una exposición.
Tariq : ¿Se puede entrar?
Inma : Sí. Es gratis. Dentro suele haber arte.
Tariq : Vamos a entrar.
(Entran en el Palacio de Cristal. Dentro hace menos calor. Hay una instalación de luces.)
Tariq : ¡Guau! ¡Qué luz tan bonita!
Inma : Sí. Es una exposición temporal.
Tariq : ¿Qué significa?
Inma : Que dura unos meses. Luego cambia.
Tariq : Qué suerte. Hoy nos toca esta.
Inma : Sí. Suele ser muy buena.
Tariq : Me gusta el color azul.
Inma : A mí el verde. Mira cómo se refleja en el suelo.
Tariq : Qué relajante.
Inma : Sí. Es un buen sitio para descansar.
Tariq : ¿Nos sentamos un momento?
Inma : Sí. Hay un banco aquí al lado.
Tariq : Gracias. Tengo los pies cansados.
Inma : Es normal. Hemos andado una hora.
Tariq : ¿Una hora? Qué rápido pasa.
Inma : Cuando se está bien, el tiempo vuela.
Tariq : Sí. Es verdad.
(Salen del Palacio de Cristal. Se acercan a un carrito de helados.)
Tariq : ¡Mira! Helados.
Inma : Hace calor. ¿Te apetece uno?
Tariq : Sí, por favor. De chocolate.
Inma : Yo de limón. Y dos con barquillo.
Heladero : Buenas tardes. Dos helados. ¿De qué sabores?
Inma : Uno de chocolate y otro de limón.
Heladero : Tres euros cada uno.
Inma : Seis euros. Toma.
Heladero : Gracias. Aquí tienen.
Tariq : Gracias.
Inma : ¿Está rico?
Tariq : Muy rico. Y muy frío.
Inma : Perfecto para el calor.
Tariq : Oye, ¿qué hacemos ahora?
Inma : Si quieres, podemos ir a las barcas.
Tariq : ¡Sí! ¿Cuánto cuesta?
Inma : Seis euros por media hora. Para dos personas.
Tariq : Vale. Yo invito.
Inma : No, no. Invito yo. Eres mi invitado.
Tariq : Gracias, prima.
Inma : De nada, primo. Vamos.
Tariq : ¿Sabes remar?
Inma : Un poco. Mi padre me enseñó de niña.
Tariq : Yo nunca he remado.
Inma : Te enseño. Es fácil, pero cansa.
Tariq : Entonces remas tú y yo hago fotos.
Inma : Ni hablar. Remamos los dos.
Tariq : Vale, vale. Pero no te rías si me caigo.
Inma : Si te caes, me río. Y te saco una foto.
Tariq : Ja, ja. Qué prima más mala.
Inma : Es la tradición familiar. Vamos al agua.
Tariq : Vamos. ¡Qué tarde más buena!

## 낭독 포인트
- z/c: «gracias», «hace», «veces», «doscientos» — c(e, i)와 z는 [θ](영어 th, thin)로 혀끝을 이 사이에 두고 낸다.
- j/g: «gente», «relajante», «refleja», «jardín» — j와 g(e, i)는 강한 [x](목 안쪽에서 나는 h 소리)로 낸다.
- ll/y: «barquillo», «brilla», «llama», «yo» — ll과 y는 [ʝ](영어 y에 가까운 소리)로 낸다.
- 억양: 안내하는 인마의 말(Mira, aquí a la derecha, el estanque)은 손으로 가리키듯 밝고 또렷하게, 타리크의 감탄(¡Qué grande!)은 올렸다 내린다. 아이스크림 주문 장면은 가볍고 빠르게.
- 숫자: ciento veinte hectáreas, treinta grados, doscientos años, seis euros를 또박또박.
- 호칭: 사촌 사이라 tú. 아이스크림 장수에게는 usted 투(Dos helados, por favor).

## 학습 포인트 정리
- A2 구간(1~20, 61~80, 101~120턴): 장소 소개와 방향
  · 장소 소개: «Mira, aquí a la derecha, el estanque.», «Allí está el Palacio de Cristal.»
  · 방향: «Todo recto.», «A la derecha.», «A la izquierda.», «Dos minutos andando.»
  · 날씨: «Hoy hay treinta grados.», «Vamos a estar a la sombra.»
- B1 구간(21~60, 81~100턴): 설명과 대화
  · 설명: «El parque fue de los reyes. Ahora es de todos.», «Es una exposición temporal. Dura unos meses.»
  · 제안: «¿Te apetece uno?», «Si quieres, podemos ir a las barcas.»
  · 관광: «Me gusta que venga gente de todo el mundo.»
- 어휘: el parque, el estanque, el paseo, la barca, el Palacio de Cristal, la sombra, el helado, la exposición.

## 속어 노트
- «Qué horror de cara»: 얼굴이 엉망이야(농담).
- «Ni hablar»: 안 돼, 말도 안 돼.
- «Poco a poco»: 천천히, 조금씩.
- «Qué tarde más buena»: 오후가 참 좋다.
- 공원 면적, 보트 요금, 아이스크림 가격은 이야기 속 설정이다. 실제 정보는 최신 안내를 확인해야 한다.
- 레지스터 주의: 욕설은 없다.

## 한글 해석
(일요일 오후 네 시. 알칼라 문과 레티로 입구. 인마가 물병을 들고 기다린다. 타리크가 모자를 쓰고 카메라를 들고 도착한다.)
인마 : 타리크! 여기야!
타리크 : 인마! 미안, 늦었어.
인마 : 괜찮아. 어떻게 지내?
타리크 : 잘 지내. 그런데 덥다.
인마 : 응. 오늘은 삼십 도야.
타리크 : 삼십 도. 우리 도시는 이보다 덜 더워.
인마 : 하지만 여기선 그늘에 있을 거야. 봐.
타리크 : 나무가 정말 많아! 엄청 크다.
인마 : 응. 레티로는 백이십 헥타르가 넘어.
타리크 : 헥타르? 많은 거야?
인마 : 많아. 축구장 백오십 개쯤.
타리크 : 정말 크다. 다 볼 수 있어?
인마 : 다는 못 봐. 하지만 제일 예쁜 건 볼 수 있어.
타리크 : 좋아. 가자.
인마 : 이 문으로 들어가. 스페인 문이야.
타리크 : 예쁘다. 오래된 거야?
인마 : 응. 대략 이백 년 전 거야.
타리크 : 이백 년. 아직도 여기 있네.
인마 : 맞아. 이 공원은 왕들의 것이었는데 지금은 모두의 것이야.
타리크 : 좋다. 무료지?
인마 : 응, 입장은 무료야. 보트를 타려면 내야 하고.
타리크 : 보트가 있어?
인마 : 응. 큰 연못에. 곧 보게 될 거야.
타리크 : 멀어?
인마 : 아니. 걸어서 이 분. 쭉 직진이야.
타리크 : 쭉 직진. 가자.
(키 큰 나무가 늘어선 넓은 길을 걷는다. 자전거 몇 대가 지나간다. 한 음악가가 기타를 치고 있다.)
타리크 : 봐! 한 남자가 기타를 쳐.
인마 : 응. 레티로에는 늘 음악이 있어.
타리크 : 분위기 좋다. 마음에 들어.
인마 : 나도. 거의 매주 일요일에 와.
타리크 : 친구들이랑?
인마 : 가끔은 친구들과, 가끔은 혼자 책 들고.
타리크 : 뭘 읽어?
인마 : 요즘은 추리소설. 제목은 '정원의 그림자'야.
타리크 : 제목 예쁘다. 재미있어?
인마 : 아주. 원하면 빌려줄게.
타리크 : 고마워, 하지만 내 스페인어로는 부족해.
인마 : 아주 잘하는데. 걱정 마.
타리크 : 고마워. 하지만 읽기는 더 어려워.
인마 : 조금씩. 봐, 여기 오른쪽에 연못이야.
타리크 : 정말 크다! 그리고 사람이 많아!
인마 : 응. 여름엔 사람이 많이 와. 색색의 보트가 있어.
타리크 : 그리고 엄청 큰 기념물도.
인마 : 알폰소 십이세 기념물이야. 햇빛에 반짝이는 것 봐.
타리크 : 응, 정말 멋져. 사진 찍어야겠다.
인마 : 그래. 물을 뒤에 두고 이쪽에 서 봐.
타리크 : 이렇게?
인마 : 조금 더 왼쪽으로. 완벽해.
타리크 : (사진을 찍는다) 됐다. 이제 너.
인마 : 아니야. 난 사진 많아.
타리크 : 제발. 한 장만.
인마 : 알았어. 한 장만. 빨리.
타리크 : 하나, 둘, 셋. 웃어.
인마 : 하하. 얼굴 끔찍하다.
타리크 : 완벽해.
인마 : 거짓말쟁이. 가자.
(연못 가를 걷는다. 보트에 사람들이 탔다. 한 쌍이 사진을 찍는다.)
타리크 : 관광객이 왜 이렇게 많아?
인마 : 아주 유명하니까. 그리고 여름이고.
타리크 : 그게 불편해?
인마 : 가끔은. 하지만 전 세계에서 사람들이 오는 건 좋아.
타리크 : 나도 그래. 나도 관광객이야.
인마 : 아니, 넌 내 사촌이야. 그건 달라.
타리크 : 하하. 고마워.
인마 : 봐, 이제 왼쪽. 저기가 크리스털 궁전이야.
타리크 : 뭐라고?
인마 : 크리스털 궁전. 전부 유리로 된 건물이야.
타리크 : 정말 예쁘다! 보석 같아.
인마 : 응. 십구 세기 건물이야. 박람회를 위해 지었어.
타리크 : 들어갈 수 있어?
인마 : 응. 무료야. 안에는 보통 미술 작품이 있어.
타리크 : 들어가 보자.
(크리스털 궁전으로 들어간다. 안은 덜 덥다. 조명 설치 작품이 있다.)
타리크 : 와! 빛이 정말 예쁘다!
인마 : 응. 기획 전시야.
타리크 : 그게 뭐야?
인마 : 몇 달 동안만 한다는 뜻이야. 그다음엔 바뀌어.
타리크 : 운이 좋네. 오늘은 이게 걸렸어.
인마 : 응. 보통 아주 좋아.
타리크 : 파란색이 마음에 들어.
인마 : 나는 초록색. 바닥에 어떻게 비치는지 봐.
타리크 : 정말 편안하다.
인마 : 응. 쉬기 좋은 곳이야.
타리크 : 잠깐 앉을까?
인마 : 응. 바로 옆에 벤치가 있어.
타리크 : 고마워. 발이 피곤해.
인마 : 당연해. 한 시간 걸었잖아.
타리크 : 한 시간? 벌써?
인마 : 좋으면 시간이 날아가지.
타리크 : 응. 맞아.
(크리스털 궁전에서 나온다. 아이스크림 수레로 다가간다.)
타리크 : 봐! 아이스크림!
인마 : 더우니까. 하나 먹을래?
타리크 : 응, 부탁해. 초콜릿으로.
인마 : 나는 레몬. 와플콘으로 두 개.
아이스크림 장수 : 안녕하세요. 아이스크림 두 개요. 무슨 맛으로 드릴까요?
인마 : 하나는 초콜릿, 하나는 레몬요.
아이스크림 장수 : 하나에 삼 유로예요.
인마 : 육 유로. 여기요.
아이스크림 장수 : 고맙습니다. 여기 있어요.
타리크 : 고마워요.
인마 : 맛있어?
타리크 : 아주 맛있어. 그리고 차가워.
인마 : 더위엔 딱이야.
타리크 : 저기, 이제 뭐 할까?
인마 : 원하면 보트 타러 가자.
타리크 : 응! 얼마야?
인마 : 삼십 분에 육 유로. 두 사람이야.
타리크 : 좋아. 내가 낼게.
인마 : 아니, 아니. 내가 낼게. 넌 내 손님이야.
타리크 : 고마워, 사촌.
인마 : 천만에, 사촌. 가자.
타리크 : 노 저을 줄 알아?
인마 : 조금. 어릴 때 아빠가 가르쳐 줬어.
타리크 : 나는 한 번도 안 저어 봤어.
인마 : 가르쳐 줄게. 쉽지만 힘들어.
타리크 : 그럼 네가 젓고 나는 사진 찍을게.
인마 : 말도 안 돼. 둘이 같이 저어.
타리크 : 알았어, 알았어. 하지만 내가 넘어져도 웃지 마.
인마 : 넘어지면 웃을 거야. 그리고 사진도 찍어 줄게.
타리크 : 하하. 못된 사촌이네.
인마 : 집안 전통이야. 물로 가자.
타리크 : 가자. 정말 좋은 오후야!
