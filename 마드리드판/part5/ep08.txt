# 5부 8화. Teatro con descuento (할인 공연)
난이도: 주 B1 | 구간: B2→A2→B1→B1→B1→B1 | 형식: 2인 | 장소: 극장 앞 광장, 로비, 객석 | 시간: 수요일 저녁 7시
등장인물: Gabi, Leandro, Acomodador, Voz, Camarero
이슈: 주 ○ 문화 공연 할인과 접근성 | 곡선: 0-1-1-0-1-0 (잔잔형, 상한 1) | 입장: 해당 없음(생활 장면. 공연 표값이 부담이라 할인 앱을 쓰는 이야기가 한마디 스침)
상황 카드: 가비와 레안드로는 극장 앞에서 만나 반값 공연 표를 확인하고 입장한다. 로비에서 프로그램을 보고, 막간에 공연에 대한 의견을 나누며 가볍게 농담한다. 걸림돌은 줄과 좌석 번호. 결말은 공연 후 근처 바에서 소감을 나누자는 약속.
학습 포인트: 할인 표 사용(la entrada con descuento, el código) · 좌석 찾기(fila, butaca) · 공연 감상(Me ha gustado, Me ha parecido) · 막간 대화 · 예의(apagar el móvil, no hablar)

## 대화
(Miércoles, siete de la tarde. La plaza frente al Teatro Español. Gabi espera con el móvil en la mano. Leandro llega con prisa, con una bufanda.)
Gabi : ¡Leandro! Por fin.
Leandro : Perdona, el metro iba lento. ¿Llevo mucho retraso?
Gabi : Diez minutos. Aún tenemos tiempo.
Leandro : Menos mal. ¿Tienes las entradas?
Gabi : Aquí en el móvil. Mira el código.
Leandro : Ah, qué bien. ¿Cuánto pagamos al final?
Gabi : Doce euros cada uno. Con descuento.
Leandro : ¿Doce? ¿Cuánto cuestan normalmente?
Gabi : Veinticuatro. Es el cincuenta por ciento.
Leandro : Qué buena oferta. ¿Dónde la encontraste?
Gabi : En una aplicación de entradas de última hora. Se publican a las cinco.
Leandro : Qué lista. Yo no sabía que existía.
Gabi : Hay muchas funciones con descuento los días de entre semana.
Leandro : Eso ayuda. El teatro es caro para quienes empiezan a trabajar.
Gabi : Sí. Hace falta un poco de estrategia.
Leandro : ¿Y tú cuántas veces vas al teatro al año?
Gabi : Unas seis. Si no hubiera descuentos, solo una.
Leandro : Yo voy poco. Me da pereza organizarme.
Gabi : Pues yo te aviso cuando salga algo bueno.
Leandro : Eso me gustaría. Pero tienes que insistir.
Gabi : Insisto. Soy muy pesada para esto.
Leandro : ¿Y con quién vas normalmente?
Gabi : Con mi hermana. Pero este mes está de viaje.
Leandro : Entonces soy el sustituto. Un honor.
Leandro : ¿Y dónde están nuestros asientos?
Gabi : Fila diez, butacas cuatro y cinco. Platea.
Leandro : Perfecto. Entonces vamos entrando.
(Se dirigen a la puerta. Un acomodador revisa las entradas.)
Acomodador : Buenas noches. ¿Me enseñan las entradas?
Gabi : Claro. Aquí tiene el código.
Acomodador : Perfecto. Fila diez. Por el pasillo de la izquierda.
Leandro : Gracias. ¿Hay guardarropa?
Acomodador : Sí, a la derecha. Es gratuito.
Leandro : Voy a dejar la bufanda. ¿Me esperas?
Gabi : Claro. Yo miro el programa.
(Leandro va al guardarropa. Gabi coge un programa de una mesa.)
Gabi : «El perro del hortelano». De Lope de Vega.
Leandro : (vuelve) ¿Qué estás leyendo?
Gabi : El programa. Dice que es una comedia del siglo diecisiete.
Leandro : ¿Del diecisiete? Seguro que el lenguaje es difícil.
Gabi : Pero la versión es moderna. Han adaptado el texto.
Leandro : Menos mal. Porque en verso rimado no entiendo nada.
Gabi : Yo tampoco. Pero dicen que la actriz principal es excelente.
Leandro : ¿Quién es?
Gabi : Carmen Linares. Ha ganado dos premios.
Leandro : Ah, sí. La vi en una serie.
Gabi : Estupendo. Entremos, que van a cerrar.
(Se sientan en sus butacas. Las luces se atenúan. Una voz pide silencio.)
Voz : Apaguen sus teléfonos móviles. Gracias.
Gabi : Apagados.
Leandro : Y el mío.
(Empieza la función. Pasan unos minutos. Se oyen risas. Después, el telón baja para el descanso.)
Leandro : Qué bueno. Me estoy riendo mucho.
Gabi : Y eso que es un texto de hace cuatrocientos años.
Leandro : La actriz es genial. Y el decorado, precioso.
Gabi : ¿Salimos al pasillo? Hay veinte minutos de descanso.
Leandro : Sí. Quiero un café.
Gabi : Yo un agua. Vamos.
(En el vestíbulo hay una barra con café, agua y bocadillos.)
Leandro : Un café solo, por favor.
Camarero : Aquí tiene. Un euro con cincuenta.
Leandro : ¿Y para ti, Gabi?
Gabi : Un agua. Gracias.
Camarero : Agua pequeña, un euro.
Gabi : Aquí. Gracias.
Leandro : ¿Qué te parece hasta ahora?
Gabi : Me gusta mucho. Pero la protagonista habla tan rápido.
Leandro : Sí, a veces no la sigo.
Gabi : Menos mal que están los subtítulos en la pantalla de arriba.
Leandro : ¿Hay subtítulos? No los había visto.
Gabi : Arriba, a la izquierda del escenario. En letras pequeñas.
Leandro : Ahora los miro en la segunda parte.
Gabi : Es una buena ayuda para entender el verso.
Leandro : Sí. Para la próxima, entradas con subtítulos.
Gabi : Suele haber funciones así los jueves.
Leandro : Tomo nota. Gracias por la información.
Gabi : ¿Y qué opinas de la escenografía?
Leandro : Muy sencilla. Pero funciona. Un jardín con cuatro paneles.
Gabi : Me gusta. A veces menos es más.
Leandro : Y los trajes, preciosos. Tienen mucho color.
Gabi : Sí. Parecen de la época, pero con algo moderno.
Leandro : ¿Sabes quién los hizo?
Gabi : Lo pone en el programa. Una diseñadora de Sevilla.
Leandro : Qué bien. Entonces la apunto también.
Gabi : Ja, ja. Vas a llenar tu libreta.
Gabi : Bueno, ¿y el argumento? ¿Lo sigues?
Leandro : Más o menos. La condesa quiere al secretario, pero no puede decirlo.
Gabi : Eso es. Y él quiere a otra, pero se enamora de ella.
Leandro : Qué lío. Es como una telenovela.
Gabi : Ja, ja. De hace cuatrocientos años.
Leandro : Hay cosas que no cambian.
Gabi : Mira, ya suena el timbre. Hay que volver.
Leandro : Vamos. No quiero perderme el final.
(Vuelven a la sala. Se apagan las luces. Empieza la segunda parte.)
(Pasan unos cuarenta minutos. Suena el aplauso final. Los actores saludan.)
Gabi : ¡Bravo! ¡Bravo!
Leandro : ¡Qué final tan bueno!
Gabi : Y qué actuación. Carmen Linares, extraordinaria.
Leandro : Ha sido genial. Me alegro de haber venido.
(La sala se vacía poco a poco. Salen al vestíbulo.)
Gabi : ¿Qué te ha parecido?
Leandro : Muy divertida. Y el texto, más claro de lo que pensaba.
Gabi : Sí, la adaptación está muy bien. Entiendo mejor a Lope ahora.
Leandro : Yo también. Antes lo evitaba. Ahora quiero leer más.
Gabi : Pues hay muchos más. «Fuenteovejuna», «La dama boba»...
Leandro : Apunto los títulos. ¿Los tienes?
Gabi : Te los mando por mensaje.
Leandro : Gracias. Oye, ¿tú crees que Lope tenía razón?
Gabi : ¿En qué?
Leandro : En lo de que el amor es más fuerte que el orgullo.
Gabi : En la obra, sí. En la vida, depende.
Leandro : Qué respuesta tan sabia.
Gabi : Me la acabo de inventar.
Leandro : Pues invéntate otra en el bar.
Gabi : Si me invitas a la segunda ronda, te invento tres.
Leandro : Trato hecho.
Leandro : Oye, ¿te apetece tomar algo?
Gabi : Sí. Hay un bar a la vuelta, con tapas.
Leandro : Perfecto. Pero esta vez, invito yo. Tú pagaste las entradas.
Gabi : No, hombre. Cada uno lo suyo.
Leandro : Ni hablar. Es una cena corta de agradecimiento.
Gabi : Está bien. Pero yo pago la propina.
Leandro : Entonces ve pensando en qué vamos a pedir.
Gabi : Unas croquetas y un vino. Lo de siempre.
Leandro : Qué previsible eres.
Gabi : Tú también. Siempre un café.
Leandro : Es un buen hábito. Venga, vamos.
Gabi : Vamos.

## 낭독 포인트
- z/c: «gracias», «entonces», «cuatrocientos», «veces» — c(e, i)와 z는 [θ](영어 th, thin)로 혀끝을 이 사이에 두고 낸다.
- j/g: «fuenteovejuna», «genial», «estrategia», «lenguaje» — j와 g(e, i)는 강한 [x](목 안쪽에서 나는 h 소리)로 낸다.
- ll/y: «pasillo», «pantalla», «sencilla», «yo» — ll과 y는 [ʝ](영어 y에 가까운 소리)로 낸다.
- 억양: 입장 전 대화는 가볍고 빠르게, 막간 감상은 약간 낮춰 진지하게, 공연 후 대화는 웃음을 섞어 올린다. 극장 안내방송(Apaguen sus teléfonos móviles)은 또렷하고 공손하게.
- 작품: «El perro del hortelano»(엘 페로 델 오르텔라노), «Fuenteovejuna»(푸엔테오베후나)는 고유 명사이므로 또박또박 읽는다.
- 호칭: 친구 사이라 tú. 안내원에게는 usted.

## 학습 포인트 정리
- B2 구간(1~20턴): 할인 표 이야기
  · 가격: «Doce euros cada uno. Con descuento.», «Veinticuatro normalmente. Es el cincuenta por ciento.»
  · 정보: «Se publican a las cinco.», «Hay muchas funciones con descuento entre semana.»
- A2 구간(21~40턴): 입장
  · 좌석: «Fila diez, butacas cuatro y cinco. Platea.», «Por el pasillo de la izquierda.»
  · 입장: «¿Me enseñan las entradas?», «¿Hay guardarropa?», «Apaguen sus teléfonos móviles.»
- B1 구간(41~120턴): 감상
  · 감상: «Me estoy riendo mucho.», «La actriz es genial.», «Muy divertida.»
  · 의견: «Más claro de lo que pensaba.», «A veces menos es más.»
  · 약속: «¿Te apetece tomar algo?», «Cada uno lo suyo.», «Trato hecho.»
- 어휘: la entrada, la platea, la butaca, el descanso, el guardarropa, el subtítulo, la escenografía, la función.

## 속어 노트
- «Menos mal»: 다행이다.
- «No, hombre»: 아니야, 그러지 마(친구 사이의 가벼운 반대).
- «Ni hablar»: 말도 안 돼, 절대 안 돼.
- «Lo de siempre»: 늘 하던 것.
- 공연 정보, 요금, 배우 이름은 이야기 속 설정이다. 실제 극장 할인과 시스템은 최신 안내를 확인해야 한다.
- 레지스터 주의: 욕설은 없다.

## 한글 해석
(수요일 저녁 일곱 시. 테아트로 에스파뇰 앞 광장. 가비가 휴대폰을 들고 기다린다. 레안드로가 목도리를 두르고 서둘러 도착한다.)
가비 : 레안드로! 드디어 왔네.
레안드로 : 미안, 지하철이 느렸어. 많이 늦었어?
가비 : 십 분. 아직 시간 있어.
레안드로 : 다행이다. 표 있어?
가비 : 휴대폰에 있어. 코드 봐.
레안드로 : 아, 좋다. 결국 얼마 내?
가비 : 한 사람당 십이 유로. 할인가야.
레안드로 : 십이? 원래는 얼마야?
가비 : 이십사 유로. 오십 퍼센트야.
레안드로 : 정말 좋은 조건이네. 어디서 찾았어?
가비 : 막판 표 앱에서. 다섯 시에 올라와.
레안드로 : 똑똑하네. 그런 게 있는 줄 몰랐어.
가비 : 평일에는 할인 공연이 많아.
레안드로 : 도움이 되네. 이제 막 일하기 시작한 사람에겐 연극이 비싸거든.
가비 : 맞아. 약간의 전략이 필요해.
레안드로 : 너는 일 년에 연극을 몇 번 봐?
가비 : 한 여섯 번. 할인이 없으면 한 번쯤이겠지.
레안드로 : 나는 거의 안 가. 챙기기 귀찮아.
가비 : 그럼 좋은 공연 나오면 내가 알려 줄게.
레안드로 : 그럼 좋겠다. 하지만 계속 챙겨 줘야 해.
가비 : 챙길게. 나 이런 건 아주 끈질겨.
레안드로 : 보통 누구랑 가?
가비 : 언니랑. 이번 달엔 여행 중이야.
레안드로 : 그럼 내가 대타네. 영광이야.
레안드로 : 우리 자리는 어디야?
가비 : 열 번째 줄, 사 번과 오 번. 일층 객석이야.
레안드로 : 좋아. 그럼 들어가자.
(문 쪽으로 간다. 안내원이 표를 확인한다.)
안내원 : 안녕하세요. 표를 보여 주시겠어요?
가비 : 그럼요. 여기 코드요.
안내원 : 좋아요. 열 번째 줄이에요. 왼쪽 통로로 가세요.
레안드로 : 고마워요. 보관소가 있나요?
안내원 : 네, 오른쪽에요. 무료입니다.
레안드로 : 목도리를 맡길게. 기다려 줄래?
가비 : 그럼. 나는 프로그램 볼게.
(레안드로가 보관소로 간다. 가비가 탁자에서 프로그램을 집는다.)
가비 : '엘 페로 델 오르텔라노'. 로페 데 베가 작품이야.
레안드로 : (돌아와서) 뭐 읽어?
가비 : 프로그램. 십칠 세기 희극이래.
레안드로 : 십칠 세기? 말이 분명 어렵겠다.
가비 : 하지만 각색 판은 현대적이래. 텍스트를 손봤대.
레안드로 : 다행이다. 운문은 하나도 못 알아듣거든.
가비 : 나도. 그래도 주연 배우가 훌륭하대.
레안드로 : 누구야?
가비 : 카르멘 리나레스. 상을 두 번 받았어.
레안드로 : 아, 맞아. 드라마에서 봤어.
가비 : 잘됐다. 들어가자, 곧 닫겠어.
(자리에 앉는다. 조명이 어두워진다. 한 목소리가 조용히 해 달라고 한다.)
목소리 : 휴대폰을 꺼 주시기 바랍니다. 감사합니다.
가비 : 껐어.
레안드로 : 나도.
(공연이 시작된다. 몇 분이 지난다. 웃음소리가 들린다. 그 뒤 막이 내려 휴식이 된다.)
레안드로 : 정말 재밌다. 많이 웃고 있어.
가비 : 사백 년 전 텍스트인데도.
레안드로 : 배우가 대단해. 무대 장치도 예쁘고.
가비 : 복도로 나갈까? 휴식이 이십 분이야.
레안드로 : 응. 커피 마시고 싶어.
가비 : 나는 물. 가자.
(로비에 커피, 물, 샌드위치가 있는 바가 있다.)
레안드로 : 에스프레소 한 잔 주세요.
종업원 : 여기요. 일 유로 오십 센트입니다.
레안드로 : 너는 뭐 마셔, 가비?
가비 : 물. 고마워.
종업원 : 작은 물 한 병, 일 유로예요.
가비 : 여기요. 고마워요.
레안드로 : 지금까지 어때?
가비 : 아주 좋아. 하지만 주인공이 너무 빨리 말해.
레안드로 : 응, 가끔 못 따라가겠어.
가비 : 다행히 위쪽 화면에 자막이 나와.
레안드로 : 자막이 있어? 못 봤는데.
가비 : 위쪽, 무대 왼쪽에. 작은 글씨로.
레안드로 : 후반에는 봐야겠다.
가비 : 운문 이해하는 데 큰 도움이 돼.
레안드로 : 응. 다음엔 자막 있는 공연으로 하자.
가비 : 보통 목요일에 그런 공연이 있어.
레안드로 : 적어 둘게. 알려 줘서 고마워.
가비 : 무대 장치는 어떻게 생각해?
레안드로 : 아주 단순해. 하지만 통해. 패널 네 개로 정원을 만들었어.
가비 : 좋아. 가끔은 덜한 게 더 나아.
레안드로 : 그리고 의상도 예뻐. 색이 풍부해.
가비 : 응. 시대 의상 같은데 현대적인 느낌도 있어.
레안드로 : 누가 만들었는지 알아?
가비 : 프로그램에 나와. 세비야 디자이너래.
레안드로 : 좋네. 그분도 적어 둘게.
가비 : 하하. 수첩이 가득 차겠다.
가비 : 그건 그렇고, 줄거리는 따라가고 있어?
레안드로 : 대충. 백작 부인이 비서를 사랑하는데 말을 못 해.
가비 : 맞아. 그리고 그는 다른 여자를 좋아하지만 그녀에게 빠져.
레안드로 : 복잡하네. 연속극 같아.
가비 : 하하. 사백 년 전 연속극이지.
레안드로 : 안 변하는 것도 있네.
가비 : 봐, 벨이 울려. 돌아가야 해.
레안드로 : 가자. 결말을 놓치고 싶지 않아.
(객석으로 돌아간다. 조명이 꺼진다. 후반부가 시작된다.)
(사십 분쯤 지난다. 마지막 박수 소리가 울린다. 배우들이 인사한다.)
가비 : 브라보! 브라보!
레안드로 : 결말 정말 좋다!
가비 : 연기도 훌륭하고. 카르멘 리나레스, 대단해.
레안드로 : 최고였어. 오길 잘했어.
(객석이 서서히 빈다. 로비로 나온다.)
가비 : 어땠어?
레안드로 : 아주 재밌었어. 텍스트도 생각보다 분명했고.
