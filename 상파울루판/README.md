- 1부 15화 모두 대화 120턴 = 한글 해석 120턴, 지문 줄 수 일치, 다섯 섹션 존재, 화자 순서 일치, 낭독 포인트의 단어가 대화에 실제로 존재함을 스크립트로 검증했다.
- 법·금액·지수·제도는 모두 가공이며 각 화 속어 노트에 적었다. 실제 적용은 확인이 필요하다.
- 원어민 검수는 아직 하지 않았다. 구어·속어와 você/tu 선택은 검수를 권장한다.
- 2~6부는 아직 작성하지 않았다.
