## 점검과 주의
- 90화 모두 대화 120턴 = 한글 해석 120턴, 지문 줄 수 일치, 다섯 섹션 존재, 화자 순서 일치, 낭독 포인트의 단어가 대화에 실제로 존재함을 스크립트로 검증했다.
- 법·금액·절차·제도는 모두 가공이며 각 화 속어 노트에 적었다. 실제 적용은 확인이 필요하다.
- 원어민 검수는 아직 하지 않았다. 구어·속어와 tu/vous 선택은 검수를 권장한다.
- 일부 화는 20턴 구간 경계가 ±1~2턴 어긋나 있을 수 있다(총 120턴은 일치).
