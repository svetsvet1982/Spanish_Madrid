# 1부 2화. Le bac jaune (노란 분리수거통)
난이도: 주 A2 | 구간: A2→B1→A2→A2→B1→A2 | 형식: 2인 | 장소: 파리 아파트 안뜰의 분리수거통 앞 | 시간: 토요일 아침 열 시
등장인물: Chloé, Arnaud
이슈: 주 ○ 분리수거 규칙과 이웃 간 가벼운 소동 | 곡선: 1-1-0-1-0-1 (반전형, 상한 1) | 입장: A 클로에(이사 온 지 사흘, 규칙을 몰라 눈치를 본다) / B 아르노(스스로 '쓰레기통 반장'을 맡았지만 바뀐 규칙은 모른다)
상황 카드: 목표: 새 이웃 클로에는 분리수거를 제대로 하고 싶다. 걸림돌: 노란 통에 붙은 쪽지를 자기에게 한 말로 오해한다. 해소: 쪽지는 아르노가 아래층 이웃에게 쓴 것이었고, 오히려 아르노가 바뀐 규칙을 잘 모른다는 것이 드러난다. 둘이 새 안내문을 함께 만들기로 하며 열린 결말.
학습 포인트: 색깔과 물건 이름(le bac jaune, le verre, le carton) · 안내 표현(Il suffit de les vider) · 명령형(Venez, Attendez) · 경어에서 반말로(On peut se tutoyer ?)

## 대화
(Une cour d'immeuble à Paris, un samedi matin. Chloé sort ses poubelles et trouve un papier sur le bac jaune.)
Chloé : Tiens, qu'est-ce que c'est que ça ? Un papier sur le bac.
Arnaud : Bonjour, mademoiselle. Vous êtes la nouvelle voisine ?
Chloé : Bonjour. Oui, j'habite au quatrième depuis lundi.
Arnaud : Bienvenue ! Moi, c'est Arnaud, du premier.
Chloé : Enchantée. Moi, c'est Chloé.
Arnaud : Vous avez une bonne tête de personne qui trie bien.
Chloé : Merci... enfin, j'essaie. Vous avez vu ce papier ?
Arnaud : Quel papier ?
Chloé : Celui-là. « Le verre, ce n'est pas dans le bac jaune ! »
Arnaud : Ah, ça. C'est moi qui l'ai mis hier.
Chloé : C'est pour moi ? J'ai jeté une bouteille mardi...
Arnaud : Une bouteille en verre ?
Chloé : Oui. Je ne savais pas. Je suis désolée.
Arnaud : Mais non, ne vous excusez pas.
Chloé : Alors ce n'est pas pour moi ?
Arnaud : Non, non. C'est pour le monsieur du deuxième.
Chloé : Ah, quel soulagement ! J'ai eu peur.
Arnaud : Ha ha, vous êtes toute rouge.
Chloé : C'est la honte. C'est mon premier week-end ici.
Arnaud : Venez, je vous explique comment ça marche.
(Arnaud ouvre les trois bacs dans la cour. Il parle avec ses mains.)
Arnaud : Alors, ici, le bac jaune, c'est pour le papier, le carton et le plastique.
Chloé : Et le bac vert ?
Arnaud : Le vert, c'est le verre. Les bouteilles, les pots de confiture, tout ça.
Chloé : D'accord. Et le gris ?
Arnaud : Le gris, c'est pour tout le reste. Les ordures normales.
Chloé : Et la boîte de pizza ? Elle est sale, avec du fromage.
Arnaud : Ah, bonne question. Une boîte sale, elle va dans le gris, pas dans le jaune.
Chloé : Mince, j'ai fait l'erreur hier soir.
Arnaud : Pas grave. Si le carton est propre, on peut le mettre dans le jaune. Si c'est gras, non.
Chloé : Compris. Il faut regarder avant de jeter.
Arnaud : Exactement. Et pour les pots de yaourt, il suffit de les vider, pas besoin de les laver à fond.
Chloé : Ah bon ? Moi, je les lavais tous les soirs.
Arnaud : Ha ha, vous perdez beaucoup d'eau, alors !
Chloé : C'est ma mère qui m'a appris ça. Elle est très stricte.
Arnaud : Elle a raison d'être stricte, mais pas trop.
Chloé : Et vous, vous faites ça depuis longtemps ?
Arnaud : Depuis vingt ans. Je suis un peu le chef des poubelles de l'immeuble.
Chloé : Le chef des poubelles ? C'est un vrai titre ?
Arnaud : Non, je me suis nommé moi-même. Personne ne voulait le poste.
Chloé : Alors merci, chef. Je prends des notes.
(Ils s'assoient sur le banc de la cour. Il fait doux. Arnaud sort un thermos de son sac.)
Arnaud : Un café ? J'en ai toujours dans mon thermos.
Chloé : Avec plaisir. Je n'ai pas encore acheté de cafetière.
Arnaud : Pas de cafetière ? Mais comment vous vivez ?
Chloé : Je bois du thé. Et je vais au café en bas, parfois.
Arnaud : Le Café du Coin ? Le patron est très gentil.
Chloé : Oui, il m'a donné un croissant gratuit lundi.
Arnaud : Il fait ça avec tous les nouveaux. C'est sa technique.
Chloé : Ha ha, ça marche très bien. J'y retourne demain.
Arnaud : Et votre appartement, il vous plaît ?
Chloé : Beaucoup. Il est petit, mais il y a du soleil le matin.
Arnaud : C'est le côté cour. Moi, j'ai le côté rue, c'est plus bruyant.
Chloé : Mais vous avez des fleurs sur votre balcon, je les ai vues.
Arnaud : Oui, des géraniums rouges. Ma femme les adorait.
Chloé : Elle n'est plus là ?
Arnaud : Elle est partie il y a trois ans. Mais les fleurs sont restées.
Chloé : Je suis désolée. Elles sont très belles.
Arnaud : Merci. Je les arrose tous les matins.
Chloé : Moi, je n'ai jamais eu de plantes. Je les oublie.
Arnaud : Je vous donne un cactus. Avec un cactus, on ne peut pas se tromper.
Chloé : D'accord, un cactus. Je vais essayer de ne pas le tuer.
(Arnaud regarde le papier sur le bac. Il devient un peu gêné.)
Arnaud : Chloé, je peux vous demander un petit service ?
Chloé : Bien sûr. Qu'est-ce qu'il y a ?
Arnaud : C'est à propos de mon papier. J'ai peut-être fait une erreur.
Chloé : Une erreur ? Mais le verre ne va pas dans le jaune, non ?
Arnaud : Non, ça, c'est vrai. Mais je ne suis plus sûr des autres règles.
Chloé : Comment ça ?
Arnaud : La mairie a changé quelque chose. Maintenant, tous les plastiques vont dans le jaune.
Chloé : Ah oui ? Même les barquettes ?
Arnaud : Je crois. Mais je ne vois pas bien les petites lettres sur l'affiche.
Chloé : Vous n'avez pas vos lunettes ?
Arnaud : Elles sont cassées. J'attends les nouvelles.
Chloé : Alors le chef des poubelles ne connaît plus les règles ?
Arnaud : Ha ha, c'est vrai. Quelle honte !
Chloé : Ne vous excusez pas. Vous voyez, c'est mon tour de vous aider.
Arnaud : Vous pouvez lire l'affiche pour moi ?
Chloé : Bien sûr. Attendez... « Tous les emballages, sans exception. »
Arnaud : Sans exception ? Même les pots de yaourt ?
Chloé : Oui. Et les barquettes, les sacs en plastique, les boîtes de conserve.
Arnaud : Eh ben ! Alors j'avais tort depuis trois mois.
Chloé : Mais pour le verre, vous aviez raison. Le verre va toujours dans le vert.
(Arnaud sort un stylo et une feuille de sa poche. Il note quelques mots.)
Arnaud : Merci, Chloé. Vous m'avez sauvé la mise.
Chloé : Ce n'est rien. Moi aussi, vous m'avez bien aidée.
Arnaud : Je voudrais refaire une affiche pour tout l'immeuble. Vous m'aidez à l'écrire ?
Chloé : Avec plaisir. Je peux la faire à l'ordinateur, si vous voulez.
Arnaud : Vraiment ? Moi, j'écrivais toujours à la main.
Chloé : À la main, c'est plus sympa, mais l'ordinateur, c'est plus lisible.
Arnaud : Vous avez raison. Et on peut mettre de grandes lettres ?
Chloé : Bien sûr. Du jaune pour le bac jaune, du vert pour le verre.
Arnaud : J'aime bien cette idée. Avec des dessins, aussi ?
Chloé : Je dessine mal, mais je peux chercher des images.
Arnaud : Quand j'étais petit, ma mère faisait des affiches pour l'école. J'adorais ça.
Chloé : Alors c'est de famille ! Vous me dites quoi mettre.
Arnaud : Mettons : « Le verre dans le vert, le reste dans le jaune. »
Chloé : Ha ha, et « les ordures dans le gris ».
Arnaud : Et « Merci de laver un peu vos pots ». Non, attendez, pas besoin de laver.
Chloé : « Merci de vider vos pots. » C'est parfait.
Arnaud : Et en bas, on met : « Signé : le chef des poubelles et la nouvelle ».
Chloé : Ha ha, ça me plaît beaucoup.
Arnaud : On imprime ça ce soir ?
Chloé : Oui, j'ai une imprimante. Je vous apporte les copies demain.
(Le soleil monte dans la cour. Un voisin passe avec une bouteille à la main, sans les voir.)
Arnaud : Chloé, on peut se tutoyer ? Vous me faites vieux.
Chloé : Bien sûr. Alors, tu m'appelles Chloé, et moi, je t'appelle Arnaud.
Arnaud : Parfait. Tiens, regarde, c'est le monsieur du deuxième.
Chloé : Il a une bouteille dans la main. Tu vas lui dire quelque chose ?
Arnaud : Non, je vais le laisser faire. S'il la met dans le vert, c'est bon.
Chloé : Et s'il la met dans le jaune ?
Arnaud : Alors je mets l'affiche sous son nez. Ha ha.
Chloé : Il va te détester !
Arnaud : Pas du tout. Il va dire merci. Il n'a jamais su, c'est tout.
Chloé : Regarde, il va vers le bac vert ! Bravo, monsieur !
Arnaud : Tu vois ? L'immeuble progresse déjà.
Chloé : Grâce au chef des poubelles.
Arnaud : Et à la nouvelle voisine qui lit les petites lettres.
Chloé : Bon, je monte. J'ai encore des cartons à ranger.
Arnaud : Des cartons propres, j'espère ?
Chloé : Très propres. Je les mets dans le jaune, promis.
Arnaud : Et demain matin, un vrai café chez moi, avec les géraniums.
Chloé : Avec plaisir. À quelle heure ?
Arnaud : Vers dix heures. Je prépare des croissants.
Chloé : Alors à demain, Arnaud. Et merci pour tout !

## 낭독 포인트
- 비음 모음: «bonjour», «enchantée», «dans le gris» — on, an, in은 코로 울리는 모음이고 n은 따로 발음하지 않는다.
- 연음: «vous avez», «les ordures», «les emballages» — s와 z 소리가 다음 모음으로 넘어간다.
- 프랑스어 r: «rouge», «merci», «très propres» — 목젖 근처에서 내는 마찰음.
- u / ou: «tu», «plus» vs «vous», «tout» — u는 입술을 모아 [y], ou는 [u].
- 묵음 e·어말 자음: «poubelles», «bouteille», «boîte» — 어말 e는 거의 소리 나지 않는다.
- 호칭·억양: «On peut se tutoyer ?» — 앞부분은 vous로 정중하게, 이 문장 뒤로는 tu로 가볍고 친근하게 읽는다. 아르노는 느리고 따뜻하게, 클로에는 밝고 빠르게.

## 학습 포인트 정리
- A2 구간(1~20턴): 첫 만남과 오해
  · 자기소개: «Moi, c'est Arnaud, du premier.», «Enchantée. Moi, c'est Chloé.»
  · 놀람과 안도: «Quel soulagement !», «C'est la honte.»
- B1 구간(21~40턴): 분리수거 규칙 설명
  · 구분 설명: «Le vert, c'est le verre.», «Si c'est gras, non.»
  · 충분 표현: «Il suffit de les vider.»
- A2 구간(41~60턴): 동네와 집 이야기
  · 현재 상태: «Moi, j'ai le côté rue, c'est plus bruyant.»
  · 미래: «Je vais essayer de ne pas le tuer.»
- A2 구간(61~80턴): 반전과 부탁
  · 부탁하기: «Vous pouvez lire l'affiche pour moi ?»
  · 고백: «Je ne suis plus sûr des autres règles.»
- B1 구간(81~100턴): 함께 안내문 만들기
  · 제안: «Mettons : ...», «Je peux la faire à l'ordinateur.»
  · 과거 습관: «Moi, j'écrivais toujours à la main.»
- A2 구간(101~120턴): 반말로 전환하고 약속하기
  · 호칭 전환: «On peut se tutoyer ?»
  · 약속: «Je les mets dans le jaune, promis.»
- 어휘: le bac, le verre, le carton, le plastique, la boîte, le pot, l'affiche, le voisin.

## 속어 노트
- «Mince»: 아이고, 이런. 가벼운 탄식으로 욕이 아니다.
- «C'est la honte»: 창피해 죽겠다.
- «Pas grave»: 괜찮아요. (ce n'est pas grave의 구어형)
- «Eh ben !»: 어휴, 아이고. 놀람을 나타낸다.
- «sauver la mise»: 곤란한 처지에서 구해 주다.
- 이 이야기의 분리수거 규칙과 색깔은 이야기 속 설정이며 실제 적용은 확인 필요.
- 레지스터 주의: 욕설은 없다. 앞부분은 vous, 101턴 이후는 tu를 쓴다.

## 한글 해석
(파리의 아파트 안뜰, 토요일 아침. 클로에가 쓰레기를 들고 나왔다가 노란 통 위에 붙은 종이를 발견한다.)
클로에 : 어, 이게 뭐지? 통 위에 종이가 붙어 있네.
아르노 : 안녕하세요, 아가씨. 새로 오신 이웃이시죠?
클로에 : 안녕하세요. 네, 월요일부터 오 층에 살아요.
아르노 : 환영해요! 저는 아르노, 이 층에 살아요.
클로에 : 반갑습니다. 저는 클로에예요.
아르노 : 분리수거 잘하게 생기셨는데요.
클로에 : 고맙습니다... 아니, 노력은 해요. 이 종이 보셨어요?
아르노 : 무슨 종이요?
클로에 : 이거요. '유리는 노란 통에 넣지 마세요!'
아르노 : 아, 그거요. 제가 어제 붙였어요.
클로에 : 저한테 쓰신 거예요? 화요일에 병을 하나 버렸는데...
아르노 : 유리병이요?
클로에 : 네. 몰랐어요. 죄송해요.
아르노 : 아니에요, 사과하지 마세요.
클로에 : 그럼 저한테 쓰신 게 아니에요?
아르노 : 아니, 아니에요. 삼 층 아저씨한테 쓴 거예요.
클로에 : 아, 다행이다! 놀랐어요.
아르노 : 하하, 얼굴이 새빨개요.
클로에 : 창피해요. 여기서 첫 주말인데요.
아르노 : 이리 오세요, 어떻게 하는지 설명해 드릴게요.
(아르노가 안뜰의 통 세 개를 연다. 손짓을 섞어 말한다.)
아르노 : 자, 여기 노란 통은 종이, 판지, 플라스틱용이에요.
클로에 : 초록 통은요?
아르노 : 초록은 유리예요. 병, 잼 통, 그런 거요.
클로에 : 알겠어요. 회색은요?
아르노 : 회색은 나머지 전부요. 일반 쓰레기요.
클로에 : 피자 상자는요? 치즈가 묻어서 더러운데요.
아르노 : 아, 좋은 질문이에요. 더러운 상자는 노란 통이 아니라 회색 통이에요.
클로에 : 이런, 어젯밤에 그 실수를 했어요.
아르노 : 괜찮아요. 판지가 깨끗하면 노란 통에 넣어도 돼요. 기름이 묻었으면 안 되고요.
클로에 : 알겠어요. 버리기 전에 봐야겠네요.
아르노 : 맞아요. 그리고 요구르트 통은 비우기만 하면 돼요, 깨끗이 씻을 필요 없어요.
클로에 : 그래요? 저는 매일 저녁 씻었는데요.
아르노 : 하하, 그럼 물을 많이 쓰셨네요!
클로에 : 어머니가 가르쳐 주셨어요. 아주 엄격하세요.
아르노 : 엄격한 게 맞아요, 너무 심하지만 않으면요.
클로에 : 아저씨는 오래 하셨어요?
아르노 : 이십 년이요. 제가 건물 쓰레기통 반장이나 다름없어요.
클로에 : 쓰레기통 반장이요? 진짜 직함이에요?
아르노 : 아뇨, 제가 저를 임명했어요. 아무도 하려 하지 않았거든요.
클로에 : 그럼 감사합니다, 반장님. 메모할게요.
(둘은 안뜰 벤치에 앉는다. 날씨가 포근하다. 아르노가 가방에서 보온병을 꺼낸다.)
아르노 : 커피 한잔할래요? 보온병에 늘 들어 있어요.
클로에 : 좋아요. 아직 커피 머신을 못 샀어요.
아르노 : 커피 머신이 없다고요? 어떻게 지내요?
클로에 : 차를 마셔요. 가끔 아래층 카페에도 가고요.
아르노 : 코앞 카페요? 주인이 아주 친절하죠.
클로에 : 네, 월요일에 크루아상을 공짜로 줬어요.
아르노 : 새 손님에게는 다 그래요. 그 사람의 기술이죠.
클로에 : 하하, 아주 잘 통해요. 내일도 갈 거예요.
아르노 : 집은 마음에 들어요?
클로에 : 아주요. 작지만 아침에 해가 들어요.
아르노 : 안뜰 쪽이라 그래요. 나는 길 쪽인데 더 시끄러워요.
클로에 : 그래도 발코니에 꽃이 있던데요, 봤어요.
아르노 : 네, 빨간 제라늄이에요. 아내가 좋아했어요.
클로에 : 부인께서는 안 계세요?
아르노 : 삼 년 전에 떠났어요. 그래도 꽃은 남았죠.
클로에 : 죄송해요. 아주 예뻐요.
아르노 : 고마워요. 매일 아침 물을 줘요.
클로에 : 저는 화분을 키워 본 적이 없어요. 자꾸 잊어버려서요.
아르노 : 선인장 하나 줄게요. 선인장은 실수할 일이 없어요.
클로에 : 좋아요, 선인장. 죽이지 않게 노력해 볼게요.
(아르노가 통 위의 종이를 바라본다. 조금 머쓱해진 얼굴이다.)
아르노 : 클로에, 작은 부탁 하나 해도 될까요?
클로에 : 그럼요. 무슨 일이에요?
아르노 : 내 종이 얘기예요. 내가 실수를 했을지도 몰라요.
클로에 : 실수요? 유리는 노란 통에 안 들어가는 거 맞잖아요?
아르노 : 네, 그건 맞아요. 그런데 다른 규칙들은 이제 자신이 없어요.
클로에 : 무슨 말씀이세요?
아르노 : 구청에서 뭘 바꿨어요. 이제 플라스틱은 전부 노란 통에 들어가요.
클로에 : 정말요? 포장 용기도요?
아르노 : 그런 것 같아요. 그런데 안내문 작은 글씨가 잘 안 보여요.
클로에 : 안경 안 쓰셨어요?
아르노 : 깨졌어요. 새 안경을 기다리는 중이에요.
클로에 : 그럼 쓰레기통 반장님이 더 이상 규칙을 모르시는 거예요?
아르노 : 하하, 맞아요. 부끄럽네요!
클로에 : 사과하지 마세요. 이번엔 제가 도와드릴 차례예요.
아르노 : 안내문 좀 읽어 줄래요?
클로에 : 그럼요. 잠깐만요... '모든 포장재, 예외 없음.'
아르노 : 예외 없이요? 요구르트 통도요?
클로에 : 네. 포장 용기, 비닐봉지, 통조림 캔도요.
아르노 : 이런! 그럼 석 달 동안 내가 틀렸네요.
클로에 : 하지만 유리는 아저씨가 맞았어요. 유리는 늘 초록 통이에요.
(아르노가 주머니에서 펜과 종이를 꺼내 몇 마디를 적는다.)
아르노 : 고마워요, 클로에. 덕분에 살았어요.
클로에 : 별말씀을요. 저도 아저씨가 많이 도와주셨어요.
아르노 : 건물 전체에 붙일 안내문을 다시 만들고 싶어요. 같이 써 줄래요?
클로에 : 기꺼이요. 원하시면 컴퓨터로 만들 수 있어요.
아르노 : 정말요? 나는 늘 손으로 썼는데.
클로에 : 손글씨가 더 정겹지만 컴퓨터는 더 읽기 쉬워요.
아르노 : 맞아요. 큰 글씨도 쓸 수 있어요?
클로에 : 물론이죠. 노란 통에는 노란색, 유리에는 초록색으로요.
아르노 : 그 생각 마음에 들어요. 그림도 넣을까요?
클로에 : 저는 그림을 못 그리지만 이미지를 찾아볼 수 있어요.
아르노 : 어릴 때 어머니가 학교 포스터를 만드셨어요. 나는 그게 참 좋았죠.
클로에 : 그럼 집안 내력이네요! 뭘 넣을지 말씀해 주세요.
아르노 : 이렇게 쓰죠. '유리는 초록 통에, 나머지는 노란 통에.'
클로에 : 하하, 그리고 '일반 쓰레기는 회색 통에'.
아르노 : 그리고 '통은 조금만 씻어 주세요'. 아니, 잠깐, 씻을 필요가 없죠.
클로에 : '통은 비워 주세요.' 완벽해요.
아르노 : 그리고 아래에 '서명: 쓰레기통 반장과 새 이웃'이라고 쓰죠.
클로에 : 하하, 정말 마음에 들어요.
아르노 : 오늘 저녁에 인쇄할까요?
클로에 : 네, 프린터가 있어요. 내일 복사본을 가져다 드릴게요.
(해가 안뜰 위로 올라온다. 한 이웃이 병을 손에 들고 둘을 보지 못한 채 지나간다.)
아르노 : 클로에, 말 놓을까요? 존댓말 들으니 늙은 것 같아요.
클로에 : 그럼요. 그럼 나를 클로에라고 불러, 나도 아르노라고 부를게.
아르노 : 좋아. 어, 봐, 삼 층 아저씨야.
클로에 : 손에 병을 들고 있어. 뭐라고 말할 거야?
아르노 : 아니, 그냥 두려고. 초록 통에 넣으면 괜찮고.
클로에 : 노란 통에 넣으면?
아르노 : 그럼 안내문을 코앞에 들이밀지. 하하.
클로에 : 너를 싫어하게 될 텐데!
아르노 : 전혀. 고맙다고 할 거야. 몰랐을 뿐이거든.
클로에 : 봐, 초록 통으로 가! 잘하셨어요, 아저씨!
아르노 : 봤지? 건물이 벌써 나아지고 있어.
클로에 : 쓰레기통 반장님 덕분이지.
아르노 : 그리고 작은 글씨를 읽어 주는 새 이웃 덕분이고.
클로에 : 자, 올라갈게. 정리할 상자가 아직 많아.
아르노 : 깨끗한 상자겠지?
클로에 : 아주 깨끗해. 노란 통에 넣을게, 약속.
아르노 : 그리고 내일 아침에는 우리 집에서 진짜 커피를 마시자, 제라늄 옆에서.
클로에 : 좋아. 몇 시에?
아르노 : 열 시쯤. 내가 크루아상을 준비할게.
클로에 : 그럼 내일 봐, 아르노. 다 고마워!
